# 中文到英文表达训练计划

这是个人学习计划，不是固定周数的课表。目标是能在未见过的生活、工作和阅读情境中，自主选择自然英文，并能解释说法改变了哪些事实或语气。教学从已有 `course/我的学习/学习者背景.md` 和真实作答出发；材料覆盖、讲过和掌握分别记录。

## 课程主轴

以**交际动作和整句表达**组织课程。单词、搭配、句式骨架、语法是完成动作的四层资源：

| 层 | 训练中问的问题 | 示例 |
|---|---|---|
| 词义 | 这个熟词在此处承担什么意义？ | `draft` 是写草稿，不等于泛泛的“准备” |
| 搭配与词组 | 哪些词经常一起完成这个动作？ | `work things out`、`write someone off` |
| 句式骨架 | 哪个半固定结构能让意思顺畅成句？ | `Part of me ..., but another part of me ...` |
| 整句表达 | 对这个人、在这个场合，我究竟怎样说？ | 邀请谈话、保留余地、明确结束，是不同动作 |

每个单元从最后一层的真实任务进入，只有卡住时才下钻前三层。可用中文和英文直译回中文作对照，但评判依据是事实、意图与语气，不是字面对齐。

## 从少到全面的阶段

| 阶段 | 主要任务 | 进入下一阶段的证据 |
|---|---|---|
| 0. 校准 | 用少量未提前教过的真实中文情境和一段自由表达，区分“本来会”“猜到”“借提示才会”；观察高频卡点 | 有可复核的原答和初步卡点分布；不据此报整体 CEFR |
| 1. 单一动作 | 一句做一件事：说明安排、提出请求、表达偏好、解释原因、描述变化；优先常见词的真实搭配 | 新题里能说清意图，不依赖同一道题的答案 |
| 2. 选择与语气 | 同一个意思换对象、关系、媒介和态度；练保留意见、委婉拒绝、澄清、评价、建议、安慰、协商 | 能在有差别的语境中选择说法，并说出选择理由 |
| 3. 连续表达 | 两三句到一条完整消息：叙事、因果、让步、指代、开场与收尾；加入必要的句式骨架 | 陌生小情境中能连贯表达，修订后没有重要信息或语气漂移 |
| 4. 跨域迁移 | 日常、关系、职场、技术、观点讨论等领域轮换；逐步减少中文提示，改用英文复述和自由表达 | 延迟复测及新领域任务仍能提取核心表达，速度和自然度随真实任务改善 |

阶段可以并行和回访。用户已经能处理不少句子主干，但主动表达尚缺基线；先用阶段 0 短试，不因过去考试成绩跳过证据，也不让阶段 1 占据整个课程。听力按现行偏好暂缓。

## 内容覆盖地图

只追求**重要功能的代表性覆盖**，不追求填满所有组合。每批选一个真实使用场景，顺带检查以下维度缺口：

| 维度 | 优先覆盖范围 |
|---|---|
| 交际动作 | 请求与回应、同意与异议、拒绝与设边界、解释与归因、评价与保留意见、选择与协商、叙事与变化、情绪与关系 |
| 领域 | 日常安排与服务、私人关系、工作协作、技术问题与决策、阅读中的观点交流；兴趣领域随用户实际材料扩充 |
| 语域与媒介 | 对朋友聊天、给同事发消息、会议讨论、邮件或书面说明；标语气差别，不强迫每题都出正式版 |
| 语言机制 | 高频多义词、搭配与介词、短语动词、句式骨架、否定与范围、条件与让步、指代与衔接、语用小词 |
| 难度 | 从一个明确意图，到多个目标冲突、隐含信息、跨句衔接、没有唯一说法的开放任务 |

课程完整度 = 重要维度有**经过使用的新语境代表任务**，并且能指出仍未覆盖的真实需求。题库数量、主题数量和单题译法数量都不能替代这个判断。一个单元只保留最常用的中性表达和确有功能差别的变体；稀有、文学化或行业专用说法单独标出。

## 计划执行顺序

1. **P0 建立小样本**：从用户真实想表达的中文、既有 Book 的卡点和一小批有出处的自然英文中选题。先核来源、语域和重复项；不要先生产大规模双语题库。
2. **P1 做一轮试练**：中文任务先出，不展示英文。保存原答；对照“信息、动作、语气、自然度”，安排新的迁移情境。评估题目是否过易、过难或缺上下文。
3. **P2 扩展成单元**：根据反复出现的卡点，按交际动作编成少量主题单元；每单元至少能让用户完成一次新情境表达。已覆盖的词组和骨架跨域复现，不机械造新条目。
4. **P3 做覆盖审计**：检查哪些交际动作、场景或语域过密／缺失；从真实英文中补表达，从真实中文使用需求中补任务。对于“标准答案”，审核是否过度翻译、语气变重或遗漏原意。
5. **P4 做延迟迁移**：在未见过的情境重做核心动作，记录独立完成与所需提示。只有这些结果能支持“更会表达”的判断；必要时调整计划，而非只增加资料。

计划、候选与实际答题分开：专题候选见[学习与内容待办](../../我的学习/学习与内容待办.md)，答题记录见每日练习页。站点可编辑已登记 Markdown，但没有对话或学习记录数据库；本循环由用户与 coach 在对话中完成。

## 日常学习回路（2026-10-13）

当前主线改为每天一组10句的真实材料精读与迁移：用户先独立译出大意、标不确定处；教练逐句解释实际卡点并给自然中文意思；从当天内容选一个表达，改到新情境中做中译英。详见[每日逐句精读与迁移练习页](../../表达练习/每日逐句精读与迁移.md)。词汇与 chunks 候选分别整理，教材专题先列在[学习与内容待办](../../我的学习/学习与内容待办.md)，经用户讨论筛选再扩编。

计划与进度分别记录在练习页和学习状态中。不因完成10句或读过讲解自动标记掌握；依据用户的初译、疑点、独立迁移与之后复习判断下一步。

## 每轮继续工作时可用的提示

> 依据 English 项目的 `translation-coach` Skill，先读取学习者档案、方法和已有进度。本轮围绕【一个真实主题或交际动作】做一小批中文到英文表达训练。先给有上下文的中文任务，不展示参考英文；保留我的原答后，区分真正错误、可用但不贴切、风格选择。给一个自然的中性表达和必要的语气变体，做英文直译回中文的差异分析，再给一个未见过的新情境。记录素材出处和练习证据，更新覆盖缺口；未练习的不算掌握，也不自动入 Book。

当用户只要求收集素材时，将上面“训练”换成“建立中文情境与英文例证的独立候选池，并报告来源、覆盖缺口和待核项”，不要替用户作答。
