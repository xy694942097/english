# English 学习资料

网页和文件系统使用同一组织方式：

```text
学习章节/
  词义与搭配/
  句式与结构/
  口语表达/
表达练习/
Chunks 收集/
原文与参考资料/
  原文、教材与影视/
  表达与语法查阅/
我的学习/
编纂与维护/
```

文档文件名取标题；nav.json 只登记顺序和可见性，不跨目录分类。站点运行方法见 [site/README.md](site/README.md)。新增文章放进对应文件夹，再登记到同名前端分组。

materials/ 保存原始下载数据及来源 manifest；references/ 保存生成工具和选材数据；engineering/ 保存工程记录与未展示旧资料；site/ 是查看器；progress/ 保留后台练习证据。它们不作为额外学习分组。

实际教学与录入规则见 [AGENTS.md](AGENTS.md)，迁移说明见 [目录迁移记录](engineering/design/documents-filesystem-2026-10-11.md)。
