# English Book

你的英语学习档案、可扩展教材与对话课堂。

2026-09-15起，默认首页按五个知识专题组织，给出明确的章节问题与建议起点。当前主线11章，其中新增nothing but、not until、特殊句子解析和take四章。词表资料库保留在查阅入口，不再作为教学主线。

## 打开课堂

在本目录运行：

```bash
python3 site/server.py
```

浏览器打开 http://127.0.0.1:4174 。网页可阅读、搜索、切换主题、折叠答案，并直接与老师对话。支持桌面和手机宽度。

## 学习工作台（第一版）

已加入较大规模的[下载词表资料](references/README.md)：四级4544词、六级3991词、专八12410词、NGSL高频核心2809词，各表有交集；关联词组单独分类。总知识库53972条，列表使用分页查询，支持词表筛选。原始文件和导入报告在references/，导入不改变学习记录。

- **知识库**：首批255个条目，来自现有词条、搭配及少量语法/句子/情境任务；不是255个新单词。按类型、中文含义、英文内容和学习状态筛选。
- **记录学习**：每条按“理解”“表达”分别记录；支持原答、提示程度与手动用时。完成首次学习后安排次日复习，可撤销。
- **今日复习**：显示到期任务，先回忆后查看参考，自评忘了/费力/顺利。到期日期持久保存；当前不发送系统通知。
- **录入**：每行一个条目，可用Tab、全角＝或空格加长破折号分隔释义。直接整理最多100行；AI补充每次最多20行。预览可编辑类型、释义、例句，选中后确认入库。相同类型、标题及含义去重，不覆盖原条目。
- **阅读关联**：词条标题旁有“记录学习”入口；正文选中文字后可通过页尾按钮转到录入。
- **表达练习**：知识库筛选“情境表达”；按中文意图尝试多个自然英文，可将回答交给右侧老师点评。
- **数据**：SQLite位于data/learning.sqlite3；知识库页底部可导出JSON或创建数据库快照。

标记“完成本次学习”不等于所有义项永久掌握。初版时间规则是可解释的调度策略，不宣称最优记忆算法。模型候选明确标为待核对、自造例句，当前没有接入外部词典API。

模型回复通过本机 `codex exec` 调用，沿用当前 Codex 登录和默认模型配置，使用账户额度。未登录时先运行 `codex login`。不用另填 API key。

## 项目入口

- [学习者背景](background/LEARNER.md)：用户自述、已观察表现、暂定假设及纠正。
- [方法与思想](background/METHOD.md)：自顶向下、实用学习、语境、迁移、证据。
- [当前状态](progress/CURRENT.md)：当前卡点与下一步；未提交的练习仍为未评估。
- [Book](book/README.md)：正式教材；[候选章节](book/BACKLOG.md)。
- [教学与编纂约定](AGENTS.md)：供老师恢复上下文和继续增编。
- [站点说明](site/README.md)：运行方式、对话边界和验证。

正式内容用 Markdown 保存，网页直接读取。新增 `book/主题/章节.md` 后点网页“刷新”即可，不需要重写前端或重新构建。

网页对话原答写入 `sessions/web/`，刷新可继续，也可从课堂记录切换。它是独立网页会话，与当前 Codex 任务共享档案，历史不会自动合并进这个任务。模型每轮收到最新档案、方法、进度、当前章节及最近 30 条网页消息；更早原答保留在文件里。

可以在 Codex 中说：“继续 english，从记录恢复”，或“扩编 english Book，加入……”。老师按约定读取文件并编纂。网页回复不会自动晋升为正式教材或掌握记录。
