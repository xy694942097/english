# English

学习与项目只有三块：**Chunks、Shadowing、词汇**。

- `course/Chunks 收集/`：整块理解与表达；精选、收集箱、按作品积累和相关练习。
- `course/Shadowing/`：YouTube等外部跟读的记录，项目不做播放器或评分。
- `course/词汇/`：生词、熟词新义、语境接法与按作品积累。

原始阅读材料在 `materials/`，来源和生成数据在 `references/`；个人背景与方法在“我的学习”，维护规则在“编纂与维护”。文件系统与前端目录一致。项目使用见[AGENTS](AGENTS.md)，只读站点运行见[site/README](site/README.md)。
