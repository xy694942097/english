# 训练素材采集与核对

本文件用于建立**可以翻译的中文情境**和**可学习的自然英文例证**。两条来源线独立；英文例证是帮助判断用法和语气的证据，不自动成为某句中文的唯一译文。现成平行文本可辅助比较，但需确认哪边是原作、哪边是译文，避免把译腔当原生英语。

## 中文任务从哪里来

按用户实际需求优先：

1. **用户原话与草稿**：真想说却写不顺的消息、讨论、问题、阅读后的复述。保留表达意图和原尝试；教材化时去掉私人身份与敏感细节。
2. **生活场景**：安排与改期、请求与拒绝、解释误会、表达感受、做决定、消费服务。自造任务标“教学设题”，不能冒称取自语料。
3. **工作与技术场景**：反馈方案、澄清风险、报告进度、说明故障、提议替代、表达不确定性；不把公司内部材料放进公开教材。
4. **自然中文材料**：有明确说话者与上下文的公开访谈、文章、对话、书面交流；记录来源和使用范围。优先短段或真实交际任务，不从金句、口号中随机截一行。

中文题要能回答：**对谁说、为何说、希望对方怎样理解或行动**。过度文艺、含义不明、靠中文双关才能成立、脱离原文无法判断的题先退回改写，不拿来考“地道”。

## 英文例证从哪里来

1. **一手自然英语**：原版文章、访谈、演讲稿、真实对话、原著、用户正在读的技术文档；保留前后文、作者／作品／章节或稳定链接。
2. **权威词典及其例句**：核实词义、搭配、语域和变体。词典说明支持用法判断，不能单靠一条例句宣称某说法“唯一地道”。
3. **项目已有可追溯材料**：`materials/` 中的教材、真题、语料和 Book 引文；先按 `materials/HANDBOOK.md` 核对来源和文本质量，再引用短例句。
4. **用户提供的原生英文**：工作文档、日常阅读片段、聊天或影视台词；先确认是否为原文，私人内容只用于当前练习或去身份化。
5. **教学自造句**：用于填补语境和迁移练习，明确标注；模型顺口生成的英文不能标为“真实语料”。

英文材料优先覆盖与当前中文意图**功能相近**的表达，不要求词语一一对应。发现自然英文时也可反向设计一个未泄露答案的中文情境题；不要直接把现成英文机械回译成中文后当高质量原创题。需要下载新资料时按 `materials/HANDBOOK.md` 登记来源、许可、文件校验，先少量抽检再批量处理。网页查证时保存实际查阅链接，不虚构出处或频次。短引文遵守来源许可，不复制整章或大量台词到教材。

只是在建议“可以去哪里找”时，可列来源类别；**未实际打开核对的具体页面或原句，只能标为待核候选**，不能给出仿佛已查验的精确链接、作者、章节或引文。先确认页面存在、文本可读、语言为原作且适合目标语域，再升为“已核来源”。

## 候选记录的最小字段

初期用 Markdown 表或 JSONL 即可，不必为采集先建数据库。中文任务与英文例证各自有来源记录，再由“表达功能”关联：

| 字段 | 含义 |
|---|---|
| `id`、`status` | 稳定编号；候选／已核来源／已出题／已练习／已入书分开 |
| `text`、`language`、`origin` | 原文；中／英；用户原话、公开原文或教学自造 |
| `source`、`location` | 文件／URL、作者、章节或定位；自造写明自造 |
| `context`、`audience`、`channel` | 前后文、对谁说、聊天／会议／文章等 |
| `intent`、`stance` | 交际动作、态度与语气；与单词标签不同 |
| `domain`、`mechanism` | 领域；词义／搭配／骨架／整句表达（可多选） |
| `notes` | 哪种改写会丢信息、改变焦点或语气；待查点 |

`status=已练习` 仍不等于掌握。学习者原答、提示程度和延迟迁移另写 `progress/`；只在用户真实作答后创建。个人私密材料可记功能和匿名情境，不必把原文复制进公开 Book。

## 一批素材怎样验收

- 中文题能在上下文里自然出现，至少有一个清楚的表达目标；同批不反复考同一骨架的换词版本。
- 英文例证确实出现于标注来源；如从 PDF/OCR 或字幕提取，回原文核对断句与上下文。
- 词组、骨架和整句表达的语义与语域有证据；资料只支持“在此语境可用”时，不夸成“所有场景都这样说”。
- 有**事实、动作、语气**的对应分析；中英字面不对齐时说明为何仍保留意图，或明确标出不可接受的意义漂移。
- 一条中文题优先保留自然中性说法，其他英文方案只在功能上有区别时收入；不给每题规定固定译法数。
- 同时报告来源类型分布、交际动作／领域覆盖缺口与尚待核查项；素材数量本身不是质量指标。

## 覆盖抽样，而非穷举

先看当前单元要解决的交际动作，再从生活、工作、关系、技术、观点等领域选**有真实用途**的代表场景；逐步加入不同受众和媒介。每轮复盘：是否只有某一领域、是否过量收高级词却缺高频搭配、是否只会套单句而不会发完整消息、是否只有一个语气版本。以真实练习的失败和新语境迁移结果调整下一批，不机械填满“领域 × 功能 × 语域”的所有格子。
