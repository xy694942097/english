Adult English learning should start from use, not from page one of a textbook.

For this track, the first goal is reading fluency:

> Seeing common English chunks and understanding them without stopping to translate word by word.

The current learning order:

1. Chunks and familiar words
2. Sentence skeletons in real reading
3. Tone and implied meaning
4. Listening

Core rule:

If a sentence is short but still hard, the problem is usually not grammar. It is often a missing chunk.

Example:

```text
The delay only compounded the problem.
```

Weak reading:

```text
delay = 延期
compound = 复合物?
problem = 问题
```

Fluent reading:

```text
compound the problem = make the problem worse
```

So the whole sentence means:

```text
延期只会让问题更严重。
```

Practice loop:

1. Notice the chunk.
2. Learn its core meaning.
3. Read three examples.
4. Translate one sentence.
5. Make one sentence from real life or work.
6. Review after a few days.
