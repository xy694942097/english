# 章节折叠与右侧自动目录

日期：2026-10-12。用户希望按标题折叠 Markdown 内容，并指出正文内不需要目录，改为右侧可关闭的抽屉。

前端继续读取文章 h2/h3 自动生成目录，源 Markdown 不需要逐篇维护索引。目录移入右侧抽屉，由顶部工具栏“本篇目录”按钮打开；点击条目或关闭按钮可收起，按 Escape 也可关闭。移动端工具栏保持可见，抽屉占屏幕宽度。

h2–h6 标题成为可点击的折叠摘要，其下正文和更深层标题随之折叠。默认展开，另有“展开正文／收起正文”控制当前文章的标题块。跳转锚点会展开目标所在的层级；参考答案沿用独立折叠，不受正文按钮影响。标题 ID 和旧文档深链格式保持不变。

验证入口为 `site/test_server.py` 与 `site/test_reader.cjs`。浏览器回归覆盖目录抽屉、折叠答案定位、第一季 1065 条词块的集／条目展开、移动端宽度、旧书签和搜索。内容源文件未改动。
