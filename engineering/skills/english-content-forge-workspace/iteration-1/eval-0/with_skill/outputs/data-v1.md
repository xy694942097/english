### Part 2 - Analysis

#### Analysis 1

<a id="a1"></a>
[[← 回到句子](#s1)]

- **难词/短语**：upstairs neighbour = 楼上邻居；at two-hour intervals = 每隔两小时；vibrate against = 震动着贴着
- **句式分析**：that 引导定语从句修饰 washing machine；had been vibrating 用过去完成进行时，强调震动一直持续到换机那一刻
- **中文意思**：楼上邻居终于同意换掉那台洗衣机了，它整夜每隔两小时就贴着我的天花板震一次。

#### Analysis 2

<a id="a2"></a>
[[← 回到句子](#s2)]

- **难词/短语**：rather than doing = 而不是做某事；dripping tap = 漏水的水龙头；take up = 占用（时间）
- **句式分析**：Rather than + 动名词置于句首表选择取舍；which 引导非限定从句，回指前面整件事（修龙头）而非某个词
- **中文意思**：我没请水管工，而是看了三个教学视频，自己修好了厨房漏水的水龙头——这活儿占掉了我整个周六下午。

#### Analysis 3

<a id="a3"></a>
[[← 回到句子](#s3)]

- **难词/短语**：letting agency = 租房中介；fob sb off with = 用…搪塞某人；in writing = 以书面形式
- **句式分析**：whenever 引导时间从句表「每次都」；spreading across... 现在分词后置修饰 mould；so 并列因果
- **中文意思**：每次我提到浴室天花板上蔓延的霉斑，租房中介都拿借口搪塞我，所以我开始把所有沟通都留书面记录。

- **句式分析**：what I used to 是 what 从句作介词 of 的宾语（付过去的一半），to 后省略了 pay；for double the speed 作对比状语
- **中文意思**：今年第三次涨价之后，我把宽带换到了一家小供应商，网速翻倍，费用却只要过去的一半。
