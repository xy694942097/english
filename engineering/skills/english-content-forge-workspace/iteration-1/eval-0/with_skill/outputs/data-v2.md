### Part 2 - 解析


---

#### 日常生活解析

**1.** 楼上邻居终于同意换掉那台洗衣机了，它整夜每隔两小时就贴着我的天花板震一次。
- 难词/短语：upstairs neighbour = 楼上邻居；at two-hour intervals = 每隔两小时；vibrate against = 震动着贴着
- 句式分析：that 引导定语从句修饰 washing machine；had been vibrating 用过去完成进行时，强调震动一直持续到换机那一刻

**2.** 我没请水管工，而是看了三个教学视频，自己修好了厨房漏水的水龙头——这活儿占掉了我整个周六下午。
- 难词/短语：rather than doing = 而不是做某事；dripping tap = 漏水的水龙头；take up = 占用（时间）
- 句式分析：Rather than + 动名词置于句首表选择取舍；which 引导非限定从句，回指前面整件事（修龙头）而非某个词

**3.** 每次我提到浴室天花板上蔓延的霉斑，租房中介都拿借口搪塞我，所以我开始把所有沟通都留书面记录。
- 难词/短语：letting agency = 租房中介；fob sb off with = 用…搪塞某人；in writing = 以书面形式
- 句式分析：whenever 引导时间从句表「每次都」；spreading across... 现在分词后置修饰 mould；so 并列因果

**4.** 今年第三次涨价之后，我把宽带换到了一家小供应商，网速翻倍，费用却只要过去的一半。
- 难词/短语：price hike = 涨价；broadband = 宽带；provider = 供应商
- 句式分析：what I used to 是 what 从句作介词 of 的宾语（付过去的一半），to 后省略了 pay；for double the speed 作对比状语

**5.** 新租约一签，最累人的部分才开始：翻检八年的家当，决定哪些东西有资格进搬家货车。
- 难词/短语：lease = 租约；sort through = 翻检整理；removal van = 搬家货车
- 句式分析：Now that 引导原因从句（既然）；冒号后用两个并列动名词短语 sorting... and deciding... 展开解释 the exhausting part；what deserves... 是 deciding 的宾语从句

**6.** 领养一只救助犬，纸面上听起来还能应付，直到我发现它在另一个房间的吸尘器哪怕嗡一声都会慌。
- 难词/短语：rescue dog = 救助犬（领养的流浪狗）；on paper = 理论上/纸面上；so much as = 哪怕只是
- 句式分析：动名词短语 Adopting... 作主语；until 从句在叙事中翻转前句预期；so much as + 动词 强调触发条件之低

**7.** 我开始前一晚就把衣服摆好、午餐装包，这悄悄消掉了早晨那阵兵荒马乱——它以前要耗掉我一半的精力。
- 难词/短语：lay out = 摆好/铺开；eat up = 耗光/耗尽
- 句式分析：which 非限定从句回指「前一晚备好」这整套做法；that used to... 定语从句修饰 chaos

**8.** 每年春天我都发誓要给阳台的收纳箱断舍离，可每年春天最后都只是重新摆了一遍，一件没扔。
- 难词/短语：vow to = 发誓要；declutter = 断舍离/清杂物；end up doing = 落得以…收场
- 句式分析：Every spring... and every spring... 的重复平行结构制造自嘲对比；end up + 现在分词表「最终结局」

**9.** 楼下酒吧申请了延时营业许可，半条街的人联名请愿，反对的理由是午夜后的现场音乐会拉低房价。
- 难词/短语：late licence = 延时营业许可；petition = 请愿书；drive down = 拉低/压低
- 句式分析：arguing that... 现在分词短语作 petition 的伴随说明；that 从句作 arguing 的宾语

**10.** 翻了一遍账单，我发现有三个订阅早就忘干净了，其中有个语言 App，我上次打开还是在疫情前。
- 难词/短语：go through = 仔细翻看；statement = 对账单/账单（不是「声明」）；subscription = 订阅服务
- 句式分析：Going through... 现在分词作时间状语；I'd forgotten about 是省略 which/that 的定语从句修饰 subscriptions；including + 名词短语插入举例

#### 旅行与出行解析

**11.** 航空公司把我改签到更晚的航班，一句道歉都没有，结果我误了末班火车，只能咬牙掏钱住机场酒店。
- 难词/短语：bump sb onto a later flight = 把乘客改签到更晚航班；shell out for = 不情愿地掏钱买
- 句式分析：without a word of apology 介词短语作让步状语；so 并列因果链：改签 → 误车 → 住店

**12.** 不管出过多少次门，我还是会行李超装，总笃信这一次真的用得上三双鞋和一台全尺寸吹风机。
- 难词/短语：overpack = 行李装太多；full-size = 全尺寸的（非便携款）
- 句式分析：No matter how + 副词 引导让步从句；convinced that... 过去分词短语作原因状语（= because I am convinced）

**13.** 酒店在订房网站上写的是「部分海景」，实际意思是：你得探出阳台栏杆，才看得见一条水缝。
- 难词/短语：partial sea view = 部分海景（酒店营销话术）；in practice = 实际上；a sliver of = 一小条/一线
- 句式分析：which 非限定从句回指营销话术并揭穿它；if 条件从句嵌在 visible 后的补足语中

**14.** 高铁线路检修，本该两小时的车程变成五个小时的爬行，沿海每个小镇都停了一遍。
- 难词/短语：undergo maintenance = 检修维护；crawl = 蠕动/龟速行进（比喻）
- 句式分析：what should have been a two-hour journey 是 what 从句作主语（本该两小时的车程）；should have been 含「本该却没」的虚拟意味

**15.** 老城区里，一位退休老师带我们走到一家家庭面馆——我们自己绝无可能找到的那种，而且我们给小费她一分不收。
- 难词/短语：old quarter = 老城区；family-run = 家庭经营的；on one's own = 靠自己
- 句式分析：we would never have found 是省略 that 的定语从句，would never have found 隐含虚拟（若无人带路）；refusing... 现在分词作伴随状语

**16.** 我完全忘了随身行李里有罐蜂蜜，直到安检把它翻出来，还出乎意料地耐心，给我讲了那条我怎么都没听说过的液体规定。
- 难词/短语：carry-on = 随身行李；liquids rule = 液态物品限制规定
- 句式分析：not... until 结构：遗忘持续到被翻出那一刻；with surprising patience 插入状语；I'd never heard of 省略 that 定语从句修饰 rule

**17.** 我花了四天才倒好时差，而到那时已经又该飞回家了，刚调好的生物钟全部作废。
- 难词/短语：time zone = 时区；undo = 撤销/抵消
- 句式分析：It took sb. + 时间 + to do 句型；by which point 是「介词 + which」非限定从句（到那个时间点），回指 four days 结束时

**18.** 租车柜台说服我升了大一圈的车，一口咬定我订的紧凑型跑不了山路——后来证明纯属胡扯。
- 难词/短语：talk sb into doing = 说服某人做某事；turn out to be = 结果证明是
- 句式分析：talk sb into doing（反义：talk sb out of）；insisting that... 现在分词作伴随状语，that 从句作宾语；which 非限定从句回指「山路跑不了」这个说法

**19.** 为了省点钱我没买旅行保险，结果偏偏就是那一趟，行李在转运途中丢了六天。
- 难词/短语：skip = 略过不买/不做；go missing = 失踪/丢失；in transit = 在运输途中
- 句式分析：had skipped 过去完成时交代更早的决定；where 引导定语从句修饰 trip（抽象「场合」也可用 where）；the one trip 的 one 强调偏偏是这次

**20.** 天气预报信誓旦旦说晴，我们天没亮就出发了，结果到上午十点来钟，整条步道都裹进了浓雾里。
- 难词/短语：set off = 出发；socked in with fog = 被浓雾封锁/笼罩；only to find = 结果却发现
- 句式分析：only to do 不定式作结果状语，专表「意料之外的坏结果」；had promised 过去完成时对比后来的现实

#### 职场与工作解析

**21.** 我老板有个习惯：转发长长的邮件串，顶上只写一句「看法？」，不知怎么就把整摊事变成了我的问题。
- 难词/短语：email thread = 邮件往来串；nothing but = 仅仅/只有
- 句式分析：have this habit of doing 表习惯（含吐槽语气）；which 非限定从句回指转发行为；make sth. my problem 是 make + 宾语 + 名词补语

**22.** 功能都做完了客户还不停改要求，所以后来我们学乖了：任何范围变更，先落签字文件再动手。
- 难词/短语：move the goalposts = 中途改变要求/规则；scope change = 范围变更；lift a finger = 动手干活（多用于否定）
- 句式分析：kept doing 表反复发生；had already built 过去完成时对比「先做完后改口」的时序；before + 动名词

**23.** 申请内部转岗的事，我先报了名才告诉现在的团队，因为我怀疑这消息只要对一个人提，立刻就会传开。
- 难词/短语：put one's name down for = 报名申请；internal transfer = 内部转岗；leak = 走漏/泄露
- 句式分析：the moment (that)... 是连词用法，= as soon as；before telling... 介词 + 动名词表先后时序

**24.** 并购消息公布以来，部门里一半人都在悄悄更新简历，也没人再装作这次重组不会裁员的模样了。
- 难词/短语：merger = 并购；reorganisation = 重组；cost jobs = 裁员/让人丢工作
- 句式分析：Since + 过去时间点，主句用现在完成进行时；pretend 的否定靠 not... any more 后置，而非 not pretends

**25.** 我的第一位导师教我最受用的一件事：把每个决定和背后的理由都写下来，因为记忆会悄悄自我改写，专挑让你好看的说法。
- 难词/短语：mentor = 导师；reasoning = 理由和依据（不是「推理」标签）；flatter = 使…显得更好看
- 句式分析：主语是 The most useful thing (that) my mentor taught me（省略 that 的定语从句）；was to write down... 不定式作表语；to flatter you 作改写的目的，带反讽

**26.** 没有议程的会我一律不去了，结果发现：人一离场，大部分会自己就散了，两行邮件收尾。
- 难词/短语：agenda = 会议议程；resolve itself = 自行化解/不了了之；two-line email = 两行邮件
- 句式分析：stop doing = 停止做（对比 stop to do = 停下来去做）；it turns out that... 表「事后发现」；once 引导条件时间从句

**27.** 年度考核一到，才发现我的贡献人人都有记录，唯独我自己没有——这教训让我学会了自己持续记功。
- 难词/短语：annual review = 年度考核；come around =（周期性事件）如期到来；a running log = 持续更新的记录
- 句式分析：had been documented 过去完成被动，对比「考核前别人已记好」；which 非限定从句回指整件事并引出教训

**28.** 在家办公省掉了通勤，却也把「晚收工」和「早上班」的边界搅模糊了，到最后两者干脆连成一场不换班的马拉松。
- 难词/短语：commute = 通勤；blur = 使模糊；shift = 班次
- 句式分析：save sb. sth. 双宾语结构（省我通勤）；between A and B 中的 A/B 用动名词对称；until 从句表渐进到质变

**29.** 新来的同事不懂就问、从不瞎猜，起初有人觉得这样慢，结果她成了升得最快的人。
- 难词/短语：new hire = 新入职员工；strike sb as = 给某人留下…印象；be promoted = 晋升
- 句式分析：what she doesn't understand 是 asks 的宾语从句；instead of + 动名词表取舍；which 从句内 initially... but... 前后反转制造对比

**30.** 谈加薪时我揣着一整年的市场行情数据去的，说实话我们老板也爽快：不到十分钟就承认，数据摆在那儿不用多讲。
- 难词/短语：pay rise = 加薪（美式：pay raise）；to his credit = 值得称赞的是；concede = 让步承认
- 句式分析：armed with... 过去分词短语作方式状语（带着武器般的证据）；to his credit 插入语；that 从句作 conceded 的宾语后置

#### 健康与运动解析

**31.** 理疗师把我的肩膀疼追根溯源到多年的不良坐姿，而不是什么真伤，开的处方是力量训练，而不是我一直指望的静养。
- 难词/短语：physio = 理疗师（physiotherapist 缩略）；trace back to = 追溯到；count on = 指望
- 句式分析：A rather than B 与 instead of the rest 双重取舍结构呼应；I'd been counting on 是省略 that 的定语从句，用过去完成进行时

**32.** 报了游泳 beginner 班，本以为自己肯定是垫底的，结果发现班上一半成年人也都是从零学起。
- 难词/短语：sign up for = 报名参加；from scratch = 从零开始
- 句式分析：assuming... 现在分词作伴随状语（= as I assumed）；only to discover 不定式表意外结果；that 从句作 discover 的宾语

**33.** 下午两点后不碰咖啡因，头两个星期觉得根本熬不住，可现在睡眠监测显示：以前几乎没有深睡的地方，如今有了。
- 难词/短语：cut out = 戒掉/停用；fortnight = 两周（英式）；sleep tracker = 睡眠监测（设备/App）
- 句式分析：Cutting out... 动名词短语作主语；felt impossible 系表结构；where there used to be 是「地点/抽象位置」关系从句，修饰 deep sleep 出现之处

**34.** 牙医警告说，要是继续夜里磨牙，五年之内就得做牙冠，所以夜间牙套反倒成了便宜的选项。
- 难词/短语：grind one's teeth = 磨牙；crown = 牙冠；night guard = 夜间防护牙套
- 句式分析：warned that 从句内嵌 if 条件句；I'd be looking at = I would be looking at，用进行式表「将面临的局面」，比 will 更具画面感

**35.** 跑第二公里就崴了脚，我基本是凭一股轴劲儿跛着挪到终点的，代价是拄了一个星期的拐。
- 难词/短语：twist one's ankle = 崴脚；out of stubbornness = 出于执拗；on crutches = 拄着拐杖
- 句式分析：After + 动名词作时间状语；mostly 副词修饰动机（主要靠轴劲儿）；pay for it with... 用「以 X 为代价」收束后果

**36.** 我的全科医生是等我记满一个月睡眠日记才把我转去睡眠门诊的，用她的话说：含糊的主诉一碰上数据就站不住脚。
- 难词/短语：GP = 全科医生（general practitioner）；refer sb to = 把某人转诊到；as she put it = 用她的话说
- 句式分析：only after 强调转诊的前提时序；as she put it 是插入的定语性从句；survive contact with data 是隐喻性用法（经得起…的检验）

**37.** 一时兴起加入的跑步俱乐部，不知不觉成了我一周的锚点——倒不全是为跑量，更多是为了跑完那杯咖啡。
- 难词/短语：on a whim = 一时兴起；anchor = 锚点/定盘星（比喻）
- 句式分析：I joined on a whim 是省略 that 的定语从句；more for A than B 比较结构点破真实动机

**38.** 每次锻炼后拉伸十分钟，起初觉得枯燥透了，但正是这一个改变，让我的腘绳肌老毛病没再犯过。
- 难词/短语：tedious = 枯燥乏味；hamstring = 腘绳肌（大腿后侧肌腱）
- 句式分析：Stretching... 动名词短语作主语；that 定语从句修饰 the single change；keep sth. from doing = 防止某事发生

**39.** 健身房一夜之间会费翻倍，我改成了居家锻炼，花了大概一个月才不再想念跑步机，开始享受那份安静。
- 难词/短语：double = 翻倍；home workout = 居家锻炼；treadmill = 跑步机
- 句式分析：it took + 时间 + to do 句型；stop doing 与 start doing 对举，形成心理转变的完整弧线

**40.** 我祖父深信早饭前散步一小时这一套，八十三岁了，爬回自己那层楼的楼梯中途都不用停下喘气。
- 难词/短语：swear by = 对…深信不疑；pause for breath = 停下来喘口气
- 句式分析：swear by 后接方法/习惯表「笃信其功效」；without + 动名词作方式状语，用「不停喘」侧写身体状态

#### 饮食与烹饪解析

**41.** 菜谱要求面团醒发一整夜，我也是吃过亏才明白：跳过这一步，布里欧修烤出来跟砖头一个手感。
- 难词/短语：call for =（菜谱/规则）要求；rest =（面团）醒发；learn the hard way = 吃过亏才懂得
- 句式分析：call for sb/sth to do 结构；skipping that step 动名词作主语；something resembling a brick 是「不定代词 + 现在分词」复合结构

**42.** 自从周日批量备餐，抽屉里那些外卖菜单都落灰了——钱包和腰围双双表示欣慰。
- 难词/短语：meal-prep = 批量备餐；gather dust = 落灰（喻闲置）；waistline = 腰围
- 句式分析：Since + 起点，主句现在完成时；which 非限定从句拟人化收尾（钱包和腰围「表示感谢」）

**43.** 菜市场摊主让我先尝后买，最后反倒劝我没买贵的莓果，买了后面便宜又熟透的那批。
- 难词/短语：vendor = 摊贩；talk sb out of = 劝阻某人别买/别做；ripe = 熟透的
- 句式分析：talk sb out of A and into B 是「劝出 A、劝进 B」的平行结构，一次交代一弃一取

**44.** 接了个电话，蒜又炒糊了，现在整锅酱都带着那股苦底味，加多少糖都盖不住。
- 难词/短语：burnt garlic = 炒糊的蒜；undertone = 隐含的味道/底味；no amount of = 再多…也不
- 句式分析：no amount of sugar can disguise 是否定强调结构（数量再多也无济于事）；that bitter undertone 用 this/that 指示限定，带「你我都懂」的口吻

**45.** 我外婆做饭全凭手感、从不称重，想复原她的饺子配方，只能盯着她的手看，用量全靠猜。
- 难词/短语：by feel = 凭手感（对比 by weights 按克重）；reconstruct = 复原/逆向重建；quantity = 用量
- 句式分析：by feel rather than by weights 介词短语平行对比；meant doing 表「意味着」；she never measured 是省略 that 的定语从句修饰 quantities

**46.** 街角新开的面包店，酸面包九点前准卖光——好不好吃，这一个事实全说明白了。
- 难词/短语：sell out of sth = 把某货卖光；sourdough = 天然酵母酸面包
- 句式分析：which 非限定从句回指「九点前卖光」；you need to know 是省略 that 的定语从句修饰 everything；how good it is 作 about 的宾语从句

**47.** 少下馆子这件事，与其说是为了省钱，不如说是重新发现：给自家厨房一把像样的刀加一点耐心，能做成什么样。
- 难词/短语：cut back on = 削减/减少；not so much A as B = 与其说 A 不如说 B；decent = 像样的
- 句式分析：动名词短语作主语；not so much... as... 固定取舍结构；what 从句作 rediscovering 的宾语

**48.** 那次家宴差点砸锅——烤菜烤到一半烤箱罢工了，幸亏邻居把自家烤箱借我，才把那个晚上救回来。
- 难词/短语：fall apart = 崩盘/砸锅；mid-roast = 烤到一半（造词式复合）；salvage = 抢救/挽回
- 句式分析：when 从句内嵌 the oven had died 过去完成时（发现时已停机）；theirs 名词性物主代词避免重复 oven

**49.** 加糖咖啡我是逐步戒的：先把糖减半，再换成黑咖啡，现在再喝老配方，甜得跟饭后甜点似的。
- 难词/短语：wean oneself off = 逐步戒除（原指给婴儿断奶）；sweetened = 加了糖的；halve = 减半
- 句式分析：first doing, then doing 并列分词序列铺陈渐进过程；taste like 感官动词表主观感受；to me 后置点明参照系

**50.** 把香草拌橄榄油冻进冰格，听着像烂大街的生活妙招——直到某个周二晚上你只想要一份罗勒，一伸手就有一块等着。
- 难词/短语：ice-cube tray = 制冰格；life-hack = 生活妙招；cliché = 老生常谈/陈词滥调
- 句式分析：动名词短语作主语；until 从句翻转前半句的轻蔑；find one waiting 是 find + 宾语 + 现在分词补语（发现它正等着）

#### 科技与数字生活解析

**51.** 我终于把十年的照片从手机迁到硬盘上，结果发现其中一半是截图，截的内容我早就忘得一干二净。
- 难词/短语：migrate = 迁移（数据）；long since = 早已（完成于很久前）
- 句式分析：that 从句作 discovered 的宾语；things I'd forgotten 是省略 that 的定语从句，过去完成时对比「截图当时」与「整理现在」

**52.** 水壶一烧水，智能音箱就听错我说话，搞得我现在冲它吼歌名，活像在跟一个糟糕的服务员艰难交涉。
- 难词/短语：mishear = 听错；take to doing = 开始养成…的习惯；track name = 歌曲名/曲目名
- 句式分析：which 非限定从句承接后果；like a man negotiating with... 是「比喻状语」，用现在分词 negotiate 收尾制造画面

**53.** 密码泄露事件之后，我把所有账号搬进了密码管理器，花的那两个小时，比凭记忆重置一整个周末的密码划算多了。
- 难词/短语：breach =（安全）泄露事件；password manager = 密码管理器
- 句式分析：the two hours (that) it took 是省略 that 的定语从句修饰 hours；felt cheaper than 比较结构权衡一次投入与长期代价

**54.** 手机现在每周给我推一份屏幕使用时间报告，虽然我烦被监控，但那些数字确实让我半夜刷手机少了一半。
- 难词/短语：nudge = 轻推提醒；screen time = 屏幕使用时间；resent = 反感；scroll = 刷（手机内容）
- 句式分析：although 让步从句；resent being monitored 是 resent + 动名词被动式；cut ... by half 表降幅（注意介词 by）

**55.** 菜谱 App 把一半功能锁在订阅墙后面，于是我用回了纸质笔记本：离线能用、淋雨能用、永远能用。
- 难词/短语：lock behind a subscription = 锁在付费订阅后面；go back to = 重拾/退回
- 句式分析：so 并列因果；that 定语从句后接三个状语（offline / in the rain / forever）递进排比，落点在 forever

**56.** 把工作群七点后设静音，头一个星期总觉得失礼，直到同事们坦白：他们也一直在等这个信号，好名正言顺地不再回消息。
- 难词/短语：set sth to silent = 设为静音；wait for A to do = 等 A 出现才做某事
- 句式分析：动名词短语 Setting... 作主语；until 翻转「失礼」的心理预期；exactly that signal 用 exactly 回指前文做法，强调心照不宣

**57.** 备份笔记本这事我一直「打算着」，每次系统弹出提醒都被我关掉，关得理直气壮，像个从没丢过论文的人。
- 难词/短语：keep meaning to = 一直打算却一直没做；back up = 备份；dismiss = 关掉提示/无视
- 句式分析：keep doing 表拖延中的惯性；with the confidence of... 比喻状语讽刺侥幸心理；who 定语从句支撑反讽

**58.** 家庭群这些年全靠我姑的语音消息维系，直到表弟教会她用语音转文字，消息长度一夜之间翻了一倍。
- 难词/短语：survive on = 靠…维持运转；voice-to-text = 语音转文字功能
- 句式分析：until 引出转折性时间点；doubled in length 是「动词 + in + 名词」表在某维度上翻倍；overnight 夸张收束

**59.** 我订的每家流媒体今年都悄悄涨了价，而唯一涨得更快的，是我花在「选看什么」上的时间。
- 难词/短语：streaming service = 流媒体平台；quietly raise = 悄悄涨价
- 句式分析：I subscribe to 是省略 that 的定语从句（注意介词 to 留在句尾）；the only thing rising 用现在分词后置修饰；deciding what to watch 是动名词 + 疑问词不定式

**60.** 为了逃离手机我买了台电子书阅读器，还真「成功」了——某种意义上：我现在躺在床上无脑刷屏，只是换了个设备。
- 难词/短语：e-reader = 电子书阅读器；in the sense that = 从某种意义上说；doomscroll = 无脑刷负面信息（网络新造词）
- 句式分析：it worked + in the sense that... 用限定性从句给「成功」打引号，构成自嘲式反讽；holding... 现在分词作伴随状语
