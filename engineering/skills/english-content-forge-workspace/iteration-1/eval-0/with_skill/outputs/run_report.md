# 执行报告：雅思难度生活场景句集（60 句）

## 任务参数

| 项 | 值 |
| --- | --- |
| 原型 | 句集型（按 english-content-forge skill 流程） |
| 难度带 | C1（雅思）：学术词/低频搭配、句长 20–35 词、多重从句与插入语 |
| 总句数 | 60（每句含难词短语 / 句式分析 / 中文意思三件套解析） |
| 领域分组 | 6 组 × 10 句：日常生活、旅行与出行、职场与工作、健康与运动、饮食与烹饪、科技与数字生活 |
| 落盘目录 | /tmp/ecf-eval1/ |

## 执行流程

1. **读 skill**：完整阅读 SKILL.md，判型为句集型，按要求继续读 `references/sentence-corpus.md`（句子质量三判据、三件套解析写法正反例、数据纪律）。
2. **定参数**：确认难度带（C1 雅思）、领域清单、总句数、落盘目录，写入 `meta.json`。
3. **分批生成数据**（不直接写文档）：
   - 第 1 批 50 句（id 1–50，覆盖前 5 个领域，每领域 10 句，领域内部再切场景防主语/动词趋同）；
   - 第 2 批 10 句（id 51–60，「科技与数字生活」领域，与前批领域隔离）；
   - 每批写完立即自检：id 连续不重复、六字段无空、`en` 长度 ≥ 15 字符防残句、`en` 无内部重复 —— 两批均一次通过。
4. **合并与全局校验**：追加合并为 `data.jsonl`，校验全局 id 恰为 1..60 连续无重复。
5. **渲染两种视图**：运行 skill 自带脚本 `render_sentences.py`，产出交错版 `data-v1.md`（句子紧跟「解析 →」锚点链接）与分组版 `data-v2.md`（按领域归组、解析区独立成 Part）。脚本内置一致性自检通过（两视图句数 60 == 60 == 数据行数，字段无缺失）。

## 质量判据落实

- **信息句**：60 句均承载具体生活事件（换洗衣机、航班改签、密码泄露、崴脚完赛、面包店九点卖光等），无操练模板句。
- **难度带贴合**：词汇层含低频搭配与习语（fob off / move the goalposts / talk sb out of / no amount of / not so much A as B 等），结构层覆盖非限定从句、介词+which、only to do、动名词主语、分词状语等雅思常见骨架。
- **解析写骨架不贴标签**：pattern_note 全部落到「下次遇到同类结构怎么拆」（如「what 从句作介词宾语，to 后省略 pay」「talk sb out of A and into B 平行结构一次交代一弃一取」）。
- **中文翻译**：口语化意译，按中文语序重组。
