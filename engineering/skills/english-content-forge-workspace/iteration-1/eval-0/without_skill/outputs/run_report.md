# Run Report — 雅思生活场景句集生成（without_skill 基线）

## 任务
生成 60 个雅思难度（CEFR B2–C1 / 雅思 6.5–7.5）的生活场景英语句子，每句带逐句解析（难词短语、句式分析、中文意思），按领域分组。

## 执行流程
1. **需求解析**：确认为 without_skill 基线运行，未读取/使用 english-content-forge skill，直接以模型自身能力生成。
2. **方案设计**：
   - 划分 6 个生活领域，每个领域 10 句，共 60 句：
     1. 家居与日常生活（01–10）
     2. 出行与交通（11–20）
     3. 餐饮与美食（21–30）
     4. 购物与消费（31–40）
     5. 健康与运动（41–50）
     6. 社交与人际关系（51–60）
   - 每句固定三段式解析：难词短语（词性 + 释义 + 必要的辨析/音标）、句式分析（时态、从句、结构功能）、中文意思。
   - 难度策略：以短语动词、习语、熟词僻义为核心考点（如 fob off / take its toll on / a grey area / live for end-of-season sales），句式覆盖定语从句、让步状语、形式主语、动名词主语、平行比较等雅思常见语法点。
3. **内容生成**：一次性撰写全部 60 句及解析，写入 `ielts_life_sentences_60.md`，含附录高频短语速查表（含复现短语交叉索引）。
4. **交付落盘**：主文件保存至 `/tmp/ecf-eval1-baseline/`，并复制到 outputs 目录。

## 产出文件

|---|---|

| `run_report.md` | 本执行报告 |
