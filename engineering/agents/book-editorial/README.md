# English Book

这是逐步编纂的个人英语教材。教材、练习、查阅资料和待修文档的角色分开；材料覆盖与个人掌握状态分开维护。完整逐篇清单与恢复条件见[编辑分层清单](../../../编纂与维护/English Book 编辑分层清单.md)。

跨专题的学习单位是宽泛的 **chunks／词块**：搭配、短语动词、习语、话语套语和句式骨架都可能值得整体识别。词块的范围、采集门槛和快反应训练见[方法说明](../../../我的学习/把 chunks 作为快速理解与表达的学习单位.md)。

## 学习入口

站点侧边栏按五个用途组织，由 `nav.json` 显式登记：

- **学习章节**：词义与搭配、句式与结构、口语表达；知识类型作为组内标签。
- **表达练习**：中文到英文表达讲解和独立情境任务。
- **Chunks 收集**：收集箱、按作品整理的词块与词汇候选。
- **原文与参考资料**：TED、影视、演讲、教材、真题和待审校查阅指南。
- **我的学习**：背景、方法、诊断与进度。

下方另有折叠的“编纂与维护”，用于格式规则、选源记录、编辑清单和 Skills。学习章节属可试教材料，查阅资料仍需按具体条目复核；分组调整不改变学习者掌握状态。文章标题下的“本文目录”可点击跳到二、三级小节，源文件不需另存一份重复目录。

从 nothing but 开始也可以，按真实卡点选章也可以。源文件路径保持稳定，侧边栏表示教学用途。

## 编纂规则

下载词表与资料见[资料库入口](../../../materials/wordlists-guide.md)。正式教材从中挑选有实际学习价值的内容；词表覆盖不代表学习掌握。

学习主线每章围绕一个阅读或表达问题，写语境、英文释义、结构、区别、例句和迁移练习。教学自造例句与真实引文分别标注；来自扫描件或社区整理版的原句还需检查文本噪声。练习先展示题目，答案单独折叠。查阅资料和候选稿在进入主线前按编辑分层清单复核。

向 Codex 说：“扩编 english Book：增加关于工作讨论的常见表达，按我的水平写。”或“给 Book 增加长句阅读章节”。老师先读取背景和当前目录，再更新 Markdown；刷新网页即可看到新内容。

当前网站是只读 Markdown 查看器。即时解释、练习反馈和正式增编在 Codex 对话中进行；学习证据写入 `progress/`，不会因网页阅读自动增加。
