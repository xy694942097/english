# English 内容编纂

项目的学习入口是[每日逐句精读与迁移](../../../course/表达练习/每日逐句精读与迁移.md)。在真实句子中确认卡点后，把可复用表达整理进[精选 Chunks](../../../course/Chunks 收集/精选 Chunks.md)，把单词义项和接法整理进[生词与熟词新义](../../../course/词汇/生词与熟词新义.md)。原文候选仍留在收集箱或按作品整理的积累页，不把“已收集”记成“已掌握”。

## 两种知识单位

- **Chunk**：固定或半固定的形式，有整体意思或表达动作，能够换语境使用。搭配、话语套语和句子骨架都可收；新卡应给原句、意思、固定部分／槽位、语气与边界。已有相同意思和用途的条目，补来源或变体，不重复建卡。
- **生词**：记录具体义项、典型接法、熟词新义、词族、近义词区别和语域。`resigned` 归词汇；`be resigned to` 作为其接法。词根或抽象“核心义”只有可核实时才用作解释。

一两个知识点不独立成章。多个条目确有共同的理解障碍、自然语境和迁移任务时，可以在现有精选文档中开小节；新建独立文档前先检查导航是否真的需要一个新入口。旧专题与完整练习存于 `engineering/archive/learning-chapters-2026-10-13/`，SHA-256 见该目录 manifest。当前展示角色与审校边界见[编辑分层清单](../../../course/编纂与维护/English Book 编辑分层清单.md)。

## 材料和证据

真实例句保留出处，教学自造例句显式标注；不确定的用法先核词典或原始语境。编辑状态与学习者掌握分开记录。候选收集不等于理解速度变快；独立理解、新情境表达和延迟复习要看实际作答。[BACKLOG](BACKLOG.md)记录未来方向，[CHANGELOG](CHANGELOG.md)记录已做改动。
