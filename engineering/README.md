# 工程与维护

学习目录与项目边界见根目录 [AGENTS.md](../AGENTS.md)。这里保留工程说明、教师执行源和验证证据。

| 目录 | 用途 |
|---|---|
| agents/ | 作品提取 Coach、编纂模板与记录；三个项目 Skill 位于 agents/skills/ |
| design/ | 当前结构调整记录、阅读器与发布说明、旧链接映射 |
| verification/ | 当前语料来源与覆盖核验 |
| archive/ | 现行核验仍依赖的总统演讲原 20 项备份 |

执行规则按 [编纂约定](../course/编纂与维护/编纂约定.md) 查找；不在多个工程说明中重复维护。项目 Skill 不在 .agents/skills 留副本或链接；独立版 Coach 仅供复制到其他对话，项目执行使用项目版。

网站使用见 [site/README](../site/README.md)，工程调整见 [三条学习轨道](design/three-learning-tracks.md)，来源与生成工具见 [references/README](../references/README.md)。真实作答留在 progress/；历史版本看 Git。

项目交付流程只维护在 [SDLC](SDLC.md)，不在各 Skill 内重复一套提交／发布流程。
