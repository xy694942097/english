# 家族A：程度与比较

本章解决：表达"超出预期""与其说A不如说B"这类评价时读不准、写不出。7 个框架，全部来自真实阅读卡点与 17 万例句库语料。标注说明：例句后标（语料）为词典例句库真实例句，标（自造）为教学自造。

## 本章预览

| 编号 | 框架 | 一句话语义 |
|---|---|---|
| 1 | more [A] than anyone had thought [B] | 超出所有人的预期上限 |
| 2 | [前项], let alone [后项] | 前项尚且达不到，后项更别提 |
| 3 | not so much [A] as [B] | 与其说[A]不如说[B] |
| 4 | nothing less than [X] / nothing short of [X] | 简直是X、不折不扣的X |
| 5 | if anything | 甚至可以说恰恰相反；要我说的话 |
| 6 | all the more [A] because [B] | 正因[B]而更[A] |
| 7 | nothing if not [A]（不常用） | 极其[A] |

## 1. more [A] than anyone had thought [B]

**语义：超出所有人的预期上限。** A 是被比较的属性，B 是人们原本以为的上限。

> Training is often much less effective than expected.（语料）

训练的效果往往远低于预期。最简形态：比较级 + than expected。

> The results were more dramatic than anyone had thought possible.（自造）

结果比任何人认为可能的都更惊人。

**结构拆解：**

```
than 从句里藏着省略：
  anyone had thought *(it)* possible
                  宾语省略 ↑  宾补
还原平语序：anyone had thought it was possible
已知结构 think it + 形容词（I thought it impossible）
被塞进 than 从句，宾语 it 不说出口
```

**变体采集：**

| 变体 | 比较基准 | 例 |
|---|---|---|
| more than words can express | 言语能表达的 | 比言语能表达的更多 |
| harder than it looks | 表象 | 比看上去难 |
| less effective than expected | 预期 | 比预期的效果差 |

## 2. [前项], let alone [后项]

**语义：前项尚且达不到，后项更别提。** 递进否定。

> Mr. Barret is not proficient in diagnosis, let alone investigation.（语料）

巴瑞特先生连诊断都不擅长，更不必提研究了。

> You had no grounds to detain Mr. Logan, let alone disrobe him.（语料）

你们连拘留洛根先生的根据都没有，更别说脱他的衣服了。

**结构拆解：**

```
let alone = 并列连词（同族 not to mention / to say nothing of）
规则：后项平行于前项同位置成分
  diagnosis（名词） → investigation（名词）
  detain（动词）    → disrobe（动词）
省略结构：let alone (you had grounds to) disrobe (him)
```

**常见误读：**

| 误读 | 正解 |
|---|---|
| 当成 leave sb alone"让…独处" | 句中逗号后的 let alone 几乎总是"更别提" |
| 后项与前项不对等 | 后项必须与前项同语法位置成分平行 |

## 3. not so much [A] as [B]

**语义：与其说[A]不如说[B]。** 否定 A 的定性，重心落在 B。

> His manner is not so much regal as professorial.（语料）

他的举止与其说帝王气派，不如说学者派头。

> She was sexually not so much chaste as prudish.（语料）

她对男女关系与其说注重贞节，毋宁说持身谨慎。

**结构拆解：**

```
A、B 必须同类语法单位（形容词对形容词、名词对名词）
语义重心在 B
肯定版对照：It was as much luck as skill（各占一半）
```

**与 more B than A 的关系：** 同义两把刀，选哪个看想先提哪个。

## 4. nothing less than [X] / nothing short of [X]

**语义：简直是X、不折不扣的X。** 双重否定顶出强肯定，评价性强。

> The way the whales are killed is nothing short of barbaric.（语料）

捕鲸的方式简直就是野蛮。

> The demo was nothing less than a revelation.（自造）

这次演示简直就是一场启示。

> The project is nothing less than mapping every gene sequence in the human body.（语料）

这个项目就是要绘制人体所有基因序列的图谱。

**结构注：** 后接名词或形容词（nothing short of barbaric / nothing less than a disaster）。语气重，正式评论用；日常口语用 simply / outright 更自然。

## 5. if anything

**语义：甚至可以说恰恰相反；要我说的话。** 修正或加强前句的评注语。

> I owe you nothing. If anything, the reverse is true.（语料）

我不欠你什么。如果说欠，是你欠我才对。

> The new version isn't slower — if anything, it's faster.（自造）

新版没变慢——要说变化，反而更快了。

**结构注：** 不占句子成分的插入语。典型用法：先摆预期，再用 if anything 反向修正。阅读线索：见到它，先找它修正的是前文哪个判断。

## 6. all the more [A] because [B]

**语义：正因[B]而更[A]。** 因果叠加到程度。

> The very compactness of the cottage made it all the more snug and appealing.（语料）

正是村舍的小巧紧凑让它格外温暖宜人。

> Her question seemed to enflame him all the more.（语料）

她的问题似乎更加激怒了他。

**结构注：** all the more 直接修饰比较级。because 从句可省，靠语境补。

## 7. nothing if not [A]（不常用）

**语义：极其[A]。** 字面"如果不是A就什么都不是"。

> The documentation is nothing if not thorough.（自造）

这份文档要论详尽，那是真的详尽。

> Providence is nothing if not coquettish.（语料）

天公要论爱捉弄人，那是真的爱捉弄人。

**结构注：** 双重否定=极强肯定，常带轻微反讽（先承认A到极致，再让转折）。与 anything but 是镜像：anything but clear = 一点不清楚；nothing if not clear = 清晰到家。

## 迁移练习

1. The fix was not so much a solution as a way of postponing the problem. 这句话认为 fix 是解决方案吗？
2. He hasn't replied to the ticket, let alone resolved it. 他解决问题了吗？"回复"呢？
3. 用 more A than anyone had thought B 写一句你工作里的真实情况（可加 let alone）。
4. The results were nothing if not consistent. 是夸还是损？consistent 本身有问题吗？
5. If anything, the second release was more stable than the first. 第二版比第一版稳定吗？if anything 在修正什么？

## 参考答案

1. 不是。not so much A as B 否定 A 的定性，作者认为它本质是"推迟问题的方式"。重心在 postponing。
2. 都没有。let alone 递进：连回复都没有，解决更谈不上。
3. 参考：The migration took longer than anyone had thought feasible, let alone acceptable. 骨架：比较级 + than anyone had thought + 宾补。
4. 表面强肯定"高度一致"，但 nothing if not 的反讽语气暗示"稳定地坏/稳定地平庸"，看下文。consistent 本身褒义中性，反讽来自语境。
5. 比。if anything 修正的是前文可能存在的相反预期，并顺势加强"更稳定"。注意：它修正预期，不反转本句。
