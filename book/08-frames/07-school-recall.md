## 1. not only [A] but (also) [B]

**语义：不只[A]而且[B]。** 递进并列，语义重心落在 B。

> The system was not only complicated but also ineffective.（语料）

这套系统不仅复杂而且效率低。

> With any treatment, postoperative recovery depends not only on the procedure, but also on the aftercare.（语料）

术后恢复不仅取决于手术本身，还取决于术后照料。

**结构拆解：**

```
A、B 必须同类：名词对名词 / 介词短语对介词短语 / 从句对从句
not only 接介词短语时直接跟在动词后：depends not only on X but also on Y
倒装变体（高中必修*）：Not only + 助动词 + 主语 + 动词
  Not only did the system fail, but it also corrupted the backups.
  —— not only 位于句首修饰整句时才倒装；连接两个短语时不倒装
```

**常见误读：** 只倒装不倒装看位置——句首修饰全句倒装，句中连接成分不倒装。also 常省略，但 but 不能换成 and（递进色彩丢失）。

## 2. so [Adj/Adv] that [S] / such [N] that [S]

**语义：如此…以至于…。** 程度导致的后果，义教阶段核心框架。

> Abby had been so deep in thought that she had walked past her aunt's car without even seeing it.（语料）

阿比想得出了神，以至于从她姨妈的车边走过都没看见。

> He met instead a look of such mild benignity that he was left baffled.（语料）

他看到的神色竟如此温和宽厚，使他困惑莫解。

**结构拆解：**

```
so + 形容词/副词        ：so deep in thought that…
such + (a/an) + 形容词 + 名词：such mild benignity that…
分界：中心词是形容词/副词用 so，是名词用 such
强化变体：so much so that…（到了这般程度以致…，正式）
```

**常见误读：** so many/much/few/little + 名词是固定例外（中心词是量词用 so）。such a 不见得带形容词——such a pity that… 同样成立。

## 3. too [Adj] (for sb) to [V]

**语义：太…而不能…。** 否定含义藏在结构里，句面没有任何否定词。

> The andirons were too hot to touch.（语料）

铁架太热了，不敢碰。

> She's got too much dignity to descend to writing anonymous letters.（语料）

她自尊心很强，绝不会自贬身份去写匿名信。

**结构拆解：**

```
too + Adj + (for 逻辑主语) + to V   ：不定式是否定结果
还原：so hot that one cannot touch it
变体：too ready to V ≠ 不能，而是"太乐于V"（only too ready to V 极其乐意）
```

**常见误读：** too...to 默认否定，但 too ready/too willing/too apt to 是肯定（"巴不得"）。判断依据是形容词的意愿色彩，不是结构本身。

## 4. either [A] or [B] / neither [A] nor [B]

**语义：二选一 / 两者皆非。** 义教阶段成对连词，词组级框架的入口样本。

> A hydrocarbon was known to be either an alkene or alkane.（语料）

已知某烃不是烯烃就是烷烃。

> When we drew level, he neither slowed down nor accelerated.（语料）

当我们齐头并进时，他既没有慢下来也没有加速。

**结构拆解：**

```
A、B 平行：动词对动词（slowed / accelerated）、名词对名词（alkene / alkane）
主谓一致就近原则：Either you or he is… / Neither he nor you are…
neither…nor 本身已含否定，谓语用肯定式（≠ not…neither）
```

**常见误读：** 谓语动词跟最近的主语走，不跟第一个。中文习惯"既不…也不…"，英文里 nor 后面不能再加 not。

## 5. the more [A], the more [B]

**语义：越…越…。** 双重比较级联动，高中必修 \* 框架。

> The more Sarah nagged her, the more stubborn Cissie became.（语料）

萨拉越对茜茜唠叨，茜茜越是固执。

> There is a downside to it: the more she remembers, the more bitter she feels about what has happened.（语料）

这有个不利之处：她记起的越多，对发生的一切就越痛苦。

**结构拆解：**

```
The + 比较级 + 主谓, the + 比较级 + 主谓
两个从句都不用 that；前句是条件，后句是结果
省略形态：The more, the better.（越…越好，只剩比较级裸奔）
语序注意：比较级可以带主语后置 —— the more necessary is it that…（语料，正式体倒装）
```

**常见误读：** the 不是定冠词而是结构标记，不能省。两个分句内部语序仍是陈述语序（除正式体倒装变体），不要仿疑问句序。

## 6. No sooner had [S] done than [S did] / Hardly had [S] done when [S did]

**语义：刚…就…。** 高中选择必修 \*\* 框架，过去完成时+部分倒装。

> No sooner had he arrived in Rome than he was kidnapped.（语料）

他刚到罗马就遭到了绑架。

> Fitzpiers had hardly been gone an hour when Grace began to sicken.（语料）

菲茨比尔斯走后不到一个小时，格雷丝就开始发病。

**结构拆解：**

```
No sooner + had + 主语 + 过去分词 + than + 一般过去时
Hardly  + had + 主语 + 过去分词 + when  + 一般过去时
no sooner/hardly 在句首触发部分倒装（had 提到主语前）
不倒装形态：He had no sooner arrived than…（同义，语序普通）
```

**常见误读：** 两套搭配固定——no sooner 配 than，hardly 配 when/scarcely 配 before，混搭是考试高频错点。时态必须完成时在前、过去时在后。

## 7. would rather [V] than [V]

**语义：宁愿…而不愿…。** 高中 \*\* 框架，取舍权衡的固定骨架。

> He would rather die than dicker over prices.（语料）

他宁愿死也不愿意讨价还价。

> We would rather withdraw the draft resolution than amend it.（语料）

与其修改决议草案，不如予以撤回。

**结构拆解：**

```
would rather + 动词原形 + than + 动词原形（两边平行，than 后不带 to）
虚拟延伸：would rather [sb] did…（宁愿别人……，用过去式表虚拟）
  I would rather you didn't touch the config.（自造）
```

**常见误读：** than 后动词不带 to；would rather sb did 是虚拟不是过去时间。与 prefer A to B（介词）区分——would rather 接动词原形，prefer 接动名词/名词。

## 新语境练习

用本章框架改写或翻译下列句子（先自己写，再展开参考答案对照）：

1. 这套方案不仅成本高，而且把发布时间推迟了整整一个月。（not only…but also，含倒装变体）
2. 她太累了，连文档都读不动了。（too…to）
3. 你练习得越多，调试时就越从容。（the more…the more）
4. 他刚提交完代码，构建就挂了。（No sooner…than）

## 参考答案

1. Not only did the plan cost more, but it also delayed the launch by a whole month.（自造；句首 not only 触发 did 倒装）
2. She was too exhausted to read even the docs.（自造；too exhausted to = 累到不能）
3. The more you practise, the calmer you get when debugging.（自造；第二个分句用 get + 形容词，比较级前置）
4. No sooner had he pushed the code than the build broke.（自造；had 提前倒装，than 后过去时）
