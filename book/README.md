# English Book

这是逐步编纂的个人英语教材。教材、练习、查阅资料和待修文档的角色分开；材料覆盖与个人掌握状态分开维护。完整逐篇清单与恢复条件见[编辑分层清单](../engineering/verification/book-editorial-inventory-2026-09-28.md)。

## 专题课程主线

站点侧边栏由 `nav.json` 登记；学习主线按阅读理解和中文到英文表达两个方向组织。阅读主线的五组来自原课程目录，当前均属“可试教、仍需持续审校”，不代表学习者已经掌握：

- **熟词生义**：resigned回顾、抽象宾语中的动词、评论文章中的抽象义。
- **读懂整句的词组**：[在语境中理解表达](01-reading/01-context.md)、异议与质疑；进展与效果。
- **句型与特殊句子**：[nothing but对照](05-patterns/01-nothing-but.md)、[not until](05-patterns/02-not-until.md)、[句子不长，结构陌生](05-patterns/03-unfamiliar-shapes.md)。
- **句式骨架（新主线）**：[什么是句式骨架：方法与索引](08-frames/00-guide.md)、[家族A：程度与比较](08-frames/01-degree-comparison.md)。句式骨架是比语法分析高一层的学习单位，源自 2026-09-16 诊断后确认的主处方。
- **单词专题与辨析**：[take专题](03-四六级词汇/10-take.md)、高效与有效、证据与结论。
- **中文到英文表达**：[关系还有没有挽回余地](10-expression/01-relationship-options.md)，从中文交际意图出发比较自然说法与语气边界。

从 nothing but 开始也可以，按真实卡点选章也可以。站点另设“表达练习”“真题与教材资料”和“查阅资料（待审校）”：大型合集可查，但不作为从头依次学完的课程。已确认含错误的文档暂时退出站点目录，源文件保留待修。源文件路径保持稳定，侧边栏表达的是**教学用途**，不是磁盘目录树。

## 编纂规则

下载词表与资料见[资料库入口](../materials/wordlists-guide.md)。正式教材从中挑选有实际学习价值的内容；词表覆盖不代表学习掌握。

学习主线每章围绕一个阅读或表达问题，写语境、英文释义、结构、区别、例句和迁移练习。教学自造例句与真实引文分别标注；来自扫描件或社区整理版的原句还需检查文本噪声。练习先展示题目，答案单独折叠。查阅资料和候选稿在进入主线前按编辑分层清单复核。

向 Codex 说：“扩编 english Book：增加关于工作讨论的常见表达，按我的水平写。”或“给 Book 增加长句阅读章节”。老师先读取背景和当前目录，再更新 Markdown；刷新网页即可看到新内容。

当前网站是只读 Markdown 查看器。即时解释、练习反馈和正式增编在 Codex 对话中进行；学习证据写入 `progress/`，不会因网页阅读自动增加。
