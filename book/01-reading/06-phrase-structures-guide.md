## Part 1：名词短语 / 动词短语 / 短语动词

### 名词短语（NP, Noun Phrase）

### 是什么

名词短语就是"以名词为核心、周围挂满修饰成分"的一组词，功能上等同于一个名词，可以做主语、宾语、表语等。

> 比如 **the big red apple on the table** 整体就是一个名词短语，核心词是 apple，其余都是它的修饰。

---

### 核心结构公式

```
// 代码块
NP = (限定词) + (前置修饰) + 核心名词 + (后置修饰)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| **限定词（Det）** | 冠词、指示词、数词、所有格等，决定名词的"范围" | a, the, this, my, three |
| **前置修饰（Pre-mod）** | 形容词、名词修饰语，放在核心词前面 | big, red, stone（stone wall） |
| **核心名词（Head N）** | 整个短语的中心词 | apple, man, idea |
| **后置修饰（Post-mod）** | 介词短语、定语从句、分词短语、不定式等，放在核心词后面 | on the table, who runs fast |

#### 各成分出现顺序（前置修饰细化）

```
// 代码块
限定词 → 序数词 → 基数词 → 性质形容词 → 大小 → 形状 → 新旧 → 颜色 → 来源 → 材料 → 名词修饰语 → 核心名词

```

> **记忆口诀**：限序基性大形新，颜来材名核心跟

---

### 例句（标注结构成分）

#### 基础结构：限定词 + 名词

1. **[the] [book]** — Det + N（那本书）
2. **[a] [cat]** — Det + N
3. **[my] [friend]** — Det(所有格) + N

#### 限定词 + 形容词 + 名词

1. **[a] [beautiful] [girl]** — Det + Adj + N
2. **[the] [old] [man]** — Det + Adj + N
3. **[three] [tall] [buildings]** — Det + Adj + N

#### 多个前置修饰（顺序很重要！）

1. **[a] [big] [round] [old] [brown] [wooden] [table]**
→ Det + 大小 + 形状 + 新旧 + 颜色 + 材料 + N
2. **[two] [small] [red] [Chinese] [paper] [lanterns]**
→ Det + 基数 + 大小 + 颜色 + 来源 + 材料 + N

#### 后置修饰（介词短语）

1. **[the] [book] [on the shelf]**
→ Det + N + PP（介词短语）
2. **[a] [man] [in a black coat]**
→ Det + N + PP

#### 后置修饰（定语从句）

1. **[the] [girl] [who won the prize]**
→ Det + N + 定语从句
2. **[the] [house] [that I grew up in]**
→ Det + N + 定语从句

#### 后置修饰（分词短语）

1. **[the] [boy] [sitting by the window]**
→ Det + N + 现在分词短语
2. **[a] [letter] [written in French]**
→ Det + N + 过去分词短语

#### 后置修饰（不定式短语）

1. **[a] [chance] [to study abroad]**
→ Det + N + 不定式短语

---

### 扩展方式

#### 1. 名词修饰名词（名词链）

```
// 代码块
[stone] [wall]        — 石墙
[bus] [driver]        — 公共汽车司机
[coffee] [shop]       — 咖啡店
[mountain] [bike]     — 山地自行车

```

> ⚠️ 被修饰的名词总是**最后一个**，前面的名词都是修饰语

#### 2. 同位语结构

```
// 代码块
[my friend] [Tom]     — "朋友"和"Tom"互为同位
[the fact] [that he lied]   — that从句作同位语

```

#### 3. 复杂嵌套

```
// 代码块
[the [discovery [of [a [new] [species]]]]]
— 名词短语里套名词短语

```

---

### 与其他短语的关系

- **NP 可作主语**：**The tall building** collapsed.
- **NP 可作宾语（在 VP 中）**：She loves **her new job**.
- **NP 可被介词引导**：in **the park**（PP 的核心是 NP）
- **NP 可嵌套**：**the student of [the best university in Beijing]** — 里面的 NP 嵌在 PP 里

---

### 中国学习者常见错误

#### ❌ 错误1：形容词顺序搞反

| 错误 | 正确 |
| --- | --- |
| a Chinese beautiful girl | a beautiful Chinese girl |
| a round big table | a big round table |

> **规律**：性质形容词（beautiful）在前，来源形容词（Chinese）在后

#### ❌ 错误2：遗漏限定词

| 错误 | 正确 |
| --- | --- |
| I bought book. | I bought **a** book. |
| She is student. | She is **a** student. |

> 可数名词单数**必须**有限定词

#### ❌ 错误3：名词链顺序搞反（汉语直译）

| 错误 | 正确 |
| --- | --- |
| driver bus（司机公共汽车） | **bus** driver |
| shop coffee（店咖啡） | **coffee** shop |

> 英语名词链：**修饰词在前，被修饰词在后**（和中文相同，但容易乱）

---

### 现实应用/练习建议

1. **阅读练习**：拿一段英文，把每个 NP 圈出来，标注限定词、修饰语、核心词
2. **扩展练习**：从一个裸名词开始不断加修饰：
```
// 代码块
dog → a dog → a big dog → a big black dog → a big black dog with spots

```
3. **翻译反向验证**：把中文名词短语翻成英文，检查修饰词顺序
4. **刻意练习形容词顺序**：背"性大形新颜来材"顺序，造10个句子

### 二、动词短语（VP, Verb Phrase）

### 是什么

动词短语是"以动词为核心，加上宾语、补语、状语等成分"的短语，是句子中描述**动作或状态**的核心部分。

> 比如 **is eating a sandwich quietly** 就是一个动词短语，核心是 eating。

---

### 核心结构公式

```
// 代码块
VP = (助动词) + 核心动词 + (宾语/补语) + (状语)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| **助动词（Aux）** | be, have, do, will, can, must 等 | is, has, will, should |
| **核心动词（Head V）** | 实义动词，VP 的语义中心 | run, eat, see, become |
| **宾语（Obj）** | 接受动作的 NP，他动词后面必须有 | a book, her, the truth |
| **补语（Comp）** | 补充说明主语或宾语的成分 | happy, a teacher |
| **状语（Adv/PP）** | 修饰动词，表时间、地点、方式等 | quickly, at noon, in the park |

---

### VP 的核心分类

#### 1. 不及物 VP（不需要宾语）

```
// 代码块
VP = V（+ 状语）

```

- She **runs every morning**.
- He **arrived late**.
- The baby **is sleeping**.

#### 2. 及物 VP（需要宾语）

```
// 代码块
VP = V + NP（宾语）

```

- She **loves chocolate**.
- He **read the book**.
- They **built a house**.

#### 3. 双宾 VP（间接宾语 + 直接宾语）

```
// 代码块
VP = V + NP(间接宾语) + NP(直接宾语)

```

- She **gave him a present**.（给他一份礼物）
- He **told me a story**.
- I **sent her a letter**.

> 也可变为：VP = V + NP(直接宾语) + to/for + NP
> - She gave **a present** to **him**.

#### 4. 系动词 VP（接补语）

```
// 代码块
VP = 系动词 + 主语补语（形容词/名词）

```

- He **is a teacher**.（V + NP 补语）
- She **feels happy**.（V + Adj 补语）
- It **smells good**.

常见系动词：be, become, seem, feel, look, taste, sound, smell, remain, turn

#### 5. 宾语 + 宾补 VP

```
// 代码块
VP = V + NP(宾语) + 宾补（形容词/名词/不定式）

```

- They **painted the wall white**.（宾 + 形容词补）
- She **called him a genius**.（宾 + 名词补）
- He **asked her to leave**.（宾 + 不定式补）
- I **saw her running**.（宾 + 分词补）

---

### 时态与体的助动词组合

```
// 代码块
简单时：  V（现在） / V-ed（过去）
进行时：  be + V-ing
完成时：  have + V-ed（过去分词）
完成进行：have + been + V-ing
情态：    can/will/must... + V（原形）
被动：    be + V-ed（过去分词）

```

#### 例句

1. **[is eating]** a sandwich — 现在进行
2. **[has finished]** the report — 现在完成
3. **[will be visiting]** London — 将来进行
4. **[should have called]** her — 情态 + 完成
5. **[was built]** in 1900 — 过去被动
6. **[has been studied]** for years — 现在完成被动

---

### 完整例句（标注 VP 成分）

1. **She [is reading] [a novel] [in the library].**
→ 助动词 + V + 宾语(NP) + 状语(PP)
2. **He [gave] [his sister] [a birthday gift].**
→ V + 间接宾语(NP) + 直接宾语(NP)
3. **They [painted] [the old fence] [bright green].**
→ V + 宾语(NP) + 宾补(Adj)
4. **The company [will have completed] [the project] [by December].**
→ 助动词群 + V + 宾语(NP) + 状语(PP)
5. **She [seems] [tired] [after the long journey].**
→ 系动词 + 主语补语(Adj) + 状语(PP)
6. **He [asked] [her] [to come earlier].**
→ V + 宾语(NP) + 宾补(不定式短语)

---

### 扩展方式

#### 状语的多种形式

- **副词**：run **quickly**, speak **loudly**
- **介词短语**：wait **at the corner**
- **不定式**：come **to see you**
- **分词短语**：left **feeling confused**
- **时间/地点从句**：call me **when you arrive**

#### VP 嵌套

- VP 内部的宾语本身是从句（名词性从句）：
  - He **said** [that he was tired].（宾语从句）
  - She **wondered** [what to do].
- VP 内宾语本身含 VP（不定式/分词）：
  - He **stopped** [to rest].（停下来休息）
  - She **kept** [running].（一直跑）

---

### 与其他短语的关系

- **VP 是句子谓语的骨架**：S + VP 是英语句子的最基本结构
- **VP 内含 NP（宾语）**：VP 和 NP 是最深度嵌套的一对
- **VP 可含 PP（介词短语）作状语**：She ran **into the room**.
- **VP 可含从句作宾语**：I know **what you did**.

---

### 中国学习者常见错误

#### ❌ 错误1：混淆及物/不及物动词

| 错误 | 正确 |
| --- | --- |
| Let's discuss about the plan. | Let's **discuss the plan**. |
| She entered into the room. | She **entered the room**. |

> discuss, enter, resemble, reach, approach 都是及物动词，**直接加宾语，不加介词**

#### ❌ 错误2：助动词后面用错动词形式

| 错误 | 正确 |
| --- | --- |
| She can sings well. | She can **sing** well. |
| He has went home. | He has **gone** home. |
| They are run every day. | They are **running** every day. |

> 规则：情态动词后接**原形**；have 后接**过去分词**；be 进行时后接 **V-ing**

#### ❌ 错误3：双宾语语序错误

| 错误 | 正确 |
| --- | --- |
| She gave a present him. | She gave **him** a present. / She gave **a present to him**. |
| Tell me the story it. | Tell me the story. / Tell the story to me. |

---

### 现实应用/练习建议

1. **时态表格练习**：选10个常用动词，把它们的所有时态/体写一遍
2. **句型替换**：把双宾句型的两种形式互换（give him a book ↔ give a book to him）
3. **听力标注**：听播客/TED，尝试识别每句话的助动词和核心动词
4. **写作扩展**：先写最简单的 S+V，然后逐步加宾语、补语、状语，感受 VP 的生长

### 三、短语动词（Phrasal Verbs）

### 是什么

短语动词是"动词 + 小词（副词或介词）"组合成的固定搭配，整体意思**不能从字面拼凑**，需要当作一个词来记。

> 比如 **give up** 不是"给上"，而是"放弃"；**break down** 不是"打破下来"，而是"崩溃/故障"。

---

### 核心结构公式

短语动词有三种基本类型：

```
// 代码块
类型1：V + 副词小品词（intransitive）
类型2：V + 介词（transitive）
类型3：V + 副词小品词 + 介词（3-part）

```

#### 常见小词（Particles）

副词小品词：up, down, out, in, off, on, away, back, over, around, through, along, forward
介词：at, for, into, with, about, to, from, after

---

### 三种类型详解

#### 类型1：不及物短语动词（V + 副词）

无宾语，不能拆分

```
// 代码块
V + Adv-particle

```

| 短语动词 | 意思 | 例句 |
| --- | --- | --- |
| break down | 崩溃；出故障 | My car broke down on the highway. |
| give up | 放弃 | Don't give up! |
| grow up | 长大 | She grew up in Beijing. |
| take off | 起飞；脱下 | The plane took off on time. |
| turn up | 出现；调大音量 | He turned up late again. |

---

#### 类型2：及物短语动词（V + 副词，有宾语）——**可分离型**

```
// 代码块
V + Adv-particle + NP（宾语）
或
V + NP（宾语）+ Adv-particle（宾语是名词可前可后，宾语是代词必须放中间）

```

| 短语动词 | 意思 | 宾语是名词 | 宾语是代词 |
| --- | --- | --- | --- |
| turn off | 关掉 | Turn **off the light** / Turn **the light off** | Turn **it** off ✅ / ~~Turn off it~~ ❌ |
| pick up | 捡起；接人 | Pick **up the kids** / Pick **the kids up** | Pick **them** up ✅ |
| put on | 穿上 | Put **on your coat** / Put **your coat on** | Put **it** on ✅ |
| fill in | 填写 | Fill **in the form** / Fill **the form in** | Fill **it** in ✅ |
| look up | 查找（词典） | Look **up the word** / Look **the word up** | Look **it** up ✅ |

> **黄金规则：代词宾语必须插在动词和小词之间！**

---

#### 类型3：及物短语动词（V + 介词）——**不可分离型**

```
// 代码块
V + Prep + NP（宾语）

```

宾语只能放在介词后面，不能插到中间。

| 短语动词 | 意思 | 正确例句 | 错误例句 |
| --- | --- | --- | --- |
| look at | 看 | Look **at the picture**. | ~~Look the picture at.~~ |
| wait for | 等待 | Wait **for the bus**. | ~~Wait the bus for.~~ |
| listen to | 听 | Listen **to music**. | ~~Listen music to.~~ |
| care for | 照顾 | She cares **for her parents**. | — |
| deal with | 处理 | We need to deal **with the problem**. | — |

---

#### 类型4：三成分短语动词（V + 副词 + 介词）——**不可分离型**

```
// 代码块
V + Adv-particle + Prep + NP

```

| 短语动词 | 意思 | 例句 |
| --- | --- | --- |
| look forward to | 期待 | I look forward **to seeing you**. |
| come up with | 想出（主意） | She came up **with a great idea**. |
| get along with | 与…相处 | I get along **with my colleagues**. |
| run out of | 用完 | We ran out **of gas**. |
| catch up with | 追上；赶上 | He caught up **with the group**. |
| put up with | 忍受 | I can't put up **with this noise**. |
| cut down on | 减少 | She's cutting down **on sugar**. |
| look down on | 看不起 | Don't look down **on others**. |

---

### 完整例句（标注结构成分）

1. **She [turned off] [the alarm].**
→ 可分离短语动词 + 名词宾语
2. **Can you [pick it up]?**
→ 可分离短语动词 + 代词宾语（插在中间！）
3. **He [gave up] [smoking].**
→ 不及物短语动词 + 动名词宾语
4. **I'm really [looking forward to] [this trip].**
→ 三成分短语动词 + 名词宾语
5. **They [ran out of] [ideas].**
→ 三成分短语动词 + 名词宾语
6. **She [broke down] after hearing the news.**
→ 不及物短语动词，无宾语
7. **We need to [deal with] [this issue] immediately.**
→ 不可分离短语动词 + 名词宾语 + 状语

---

### 扩展方式：同一动词的多义短语动词矩阵

以 **"get"** 为例：

| 短语动词 | 意思 | 例句 |
| --- | --- | --- |
| get up | 起床 | I get up at 7. |
| get on | 上车；进展 | Get on the bus. / How are you getting on? |
| get off | 下车；离开 | Get off at the next stop. |
| get out | 出去；泄露 | Get out of here! / The secret got out. |
| get along with | 相处融洽 | I get along with everyone. |
| get over | 克服；恢复 | She got over her cold. |
| get through | 通过；度过 | I can't get through to him (电话打不通). |
| get back | 回来；取回 | When are you getting back? |
| get away | 逃走；离开 | He got away from the city for a weekend. |
| get ahead | 取得进步 | Hard work helps you get ahead. |

### 语义透明度谱系

```
// 代码块
完全透明 ←————————————→ 完全不透明（习语化）

sit down         look for         give up        kick the bucket
（坐下，字面）  （寻找，较透明） （放弃，半透明） （死，完全习语）

```

---

### 与其他短语的关系

- **短语动词是 VP 的核心动词部分**：短语动词整体充当 VP 的谓语核心
  - She **gave up** [her dream]. → VP = [gave up][her dream]
- **宾语是 NP**：及物短语动词后面跟 NP 作宾语
  - I **looked up** [every word] [in the dictionary].
- **三成分短语动词的介词后可接动名词（gerund NP）**：
  - I'm looking forward to **seeing** you.（to 后面是动名词，不是不定式）

---

### 中国学习者常见错误

#### ❌ 错误1：代词宾语位置错误（最高频错误！）

| 错误 | 正确 |
| --- | --- |
| Turn off it. | Turn **it** off. |
| Pick up them. | Pick **them** up. |
| Look up it in the dictionary. | Look **it** up in the dictionary. |

> **口诀：代词要插队，夹在动词和小词之间**

#### ❌ 错误2：look forward to 后接不定式

| 错误 | 正确 |
| --- | --- |
| I look forward to **see** you. | I look forward to **seeing** you. |
| She's looking forward to **go** on vacation. | She's looking forward to **going** on vacation. |

> **"to" 在这里是介词，不是不定式符号，后面必须接动名词（V-ing）**

#### ❌ 错误3：把不可分离的短语动词强行拆开

| 错误 | 正确 |
| --- | --- |
| Look the board at. | Look **at the board**. |
| Deal the problem with. | Deal **with the problem**. |
| Wait the bus for. | Wait **for the bus**. |

> V + 介词类型的短语动词（look at, wait for, care for）**不可分离**

---

### 现实应用/练习建议

1. **主题记忆法**：按核心动词分组记，如把所有 "get" 的短语动词、"take" 的短语动词集中攻克
2. **语境例句法**：每个短语动词造2个真实语境例句（职场、生活），而不是死背定义
3. **代词替换练习**：写10个含可分离短语动词的句子，然后把宾语换成代词，强化代词插队感
4. **美剧/播客追踪**：边听边记下遇到的短语动词，注意母语者如何使用
5. **写作刻意使用**：写日记或练习文章时，强制用5个今天学的短语动词
6. **高频500记忆**：短语动词不需要全记，重点攻克高频500个（可搜"500 most common phrasal verbs"）

## 总结对比表（Part 1）

| 维度 | 名词短语（NP） | 动词短语（VP） | 短语动词 |
| --- | --- | --- | --- |
| **核心词** | 名词 | 动词 | 动词+小词（整体） |
| **主要功能** | 作主语、宾语、表语 | 作谓语（动作/状态） | 充当 VP 的动词核心 |
| **典型扩展** | 加形容词、PP、从句 | 加助动词、宾语、状语 | 加宾语（NP/从句） |
| **关键规则** | 修饰词顺序固定 | 助动词+动词形式搭配 | 代词宾语必须居中 |
| **最难点** | 形容词排列顺序 | 时态/体的助动词选择 | 可分离/不可分离判断 |
| **相互关系** | 作为 VP 的宾语 | 包含 NP（宾语） | 是 VP 的特殊形式 |

---

> **学习建议**：三类短语互为依存——学会了 NP 的构成，才能精确表达 VP 的宾语；学会了 VP 的结构，才能正确嵌入短语动词。建议配合真实阅读/听力材料，在语境中同时观察三种短语的配合。

## Part 2：形容词短语 / 副词短语 / 介词短语 / 不定式短语

> 本部分聚焦四类核心短语：AdjP、AdvP、PP、Infinitive Phrase。
> 每个概念都从"是什么 → 怎么造 → 怎么扩展 → 例句 → 与其他短语的关系 → 常见错误 → 怎么练"全面覆盖。

---

### 一、形容词短语（AdjP, Adjective Phrase）

### 1.1 是什么

**一句话定义：** 以形容词为核心，可以在前后加修饰成分，整体用来描述名词或做表语的短语。

> 最简单的 AdjP 就一个词：*tall*。加上修饰就变成：*very tall*、*tall enough*、*proud of his work*。

---

### 1.2 核心结构公式

```
// 代码块
AdjP = (PreModifier) + Adjective HEAD + (PostModifier)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| PreModifier（前置修饰） | 副词，修饰形容词的程度/方式 | very, quite, extremely, so, too, rather |
| Adjective HEAD（核心形容词） | **必须有**，整个短语的中心词 | tall, happy, proud, easy |
| PostModifier（后置修饰） | 介词短语 / 不定式 / 从句，说明形容词的对象或条件 | of his work, to do, that... |

#### 三种基本形态

**① 纯形容词（最简）**

```
// 代码块
[Adj]

```

- *She is tall.*
- *The weather is cold.*

**② 副词 + 形容词**

```
// 代码块
[AdvP] + [Adj]

```

- *She is very tall.*
- *The movie was incredibly boring.*
- *He seems quite nervous.*

**③ 形容词 + 后置修饰（介词短语 / 不定式 / that从句）**

```
// 代码块
[Adj] + [PP / InfP / that-clause]

```

- *He is proud [of his daughter].*  → Adj + PP
- *She is eager [to learn].*  → Adj + InfP
- *I am sure [that he will come].*  → Adj + that-clause
- *The problem is easy [to solve].*  → Adj + InfP（被动含义）

**④ 副词 + 形容词 + 后置修饰（完整形态）**

```
// 代码块
[AdvP] + [Adj] + [PP / InfP / that-clause]

```

- *He is very proud of his work.*
- *She was too tired to continue.*
- *I'm quite sure that he's right.*

---

### 1.3 扩展方式

#### 扩展一：堆叠副词修饰

```
// 代码块
She is absolutely terrifyingly beautiful.
（absolutely → terrifyingly → beautiful）

```

副词可以修饰副词，形成链式修饰，但超过两层就显得啰嗦。

#### 扩展二：形容词后跟复杂 PP

```
// 代码块
proud + [of + NP]
    → proud of [the work he has done over the years]

```

#### 扩展三：形容词后跟不定式（含自己的补语）

```
// 代码块
happy + [to meet + you here]
    → happy to meet you here

```

#### 扩展四：比较结构

```
// 代码块
[Adj] + -er/more + than + NP/clause

```

- *She is taller than her sister.*
- *This is more difficult than I expected.*

#### 扩展五：最高级

```
// 代码块
the + [Adj]-est / the most + [Adj]

```

- *He is the smartest student in the class.*

---

### 1.4 例句（标注结构）

| 句子 | 结构分析 |
| --- | --- |
| She is **very happy**. | AdvP(very) + Adj(happy) |
| He is **proud of his team**. | Adj(proud) + PP(of his team) |
| The task is **difficult to complete**. | Adj(difficult) + InfP(to complete) |
| I'm **absolutely certain that you're right**. | AdvP(absolutely) + Adj(certain) + that-clause |
| She was **too exhausted to speak**. | AdvP(too) + Adj(exhausted) + InfP(to speak) |

---

### 1.5 与其他短语的关系

- **AdjP 在 NP 中前置**：做定语，放在名词前。
  - *a very tall man* → AdjP 嵌入 NP
- **AdjP 在 NP 中后置**（形容词带补语时必须后置）：
  - *a man proud of his work* → 不能说 *a proud of his work man*
- **AdjP 做表语**（系动词后）：
  - *She seems extremely tired.* → AdjP 做 subject complement
- **AdjP 做宾语补语**：
  - *I find the book very interesting.* → AdjP 补充说明宾语

---

### 1.6 中国学习者常见错误

#### ❌ 错误1：带补语的 AdjP 仍放名词前

> ❌ *a proud of his work man*
> ✅ *a man proud of his work*

**规则**：形容词一旦带了后置成分（PP、不定式等），整个 AdjP 必须后置于名词。

---

#### ❌ 错误2：滥用 very 修饰不可级形容词

> ❌ *very unique / very perfect / very dead*
> ✅ *truly unique / absolutely perfect / completely dead*

**规则**：unique、perfect、dead、pregnant 等"绝对形容词"本身已是极致，不能用程度副词 very 修饰（可用 truly/absolutely/completely 等）。

---

#### ❌ 错误3：形容词 + 介词搭配直接套汉语逻辑

> ❌ *interested at / afraid from / good in math*
> ✅ *interested in / afraid of / good at math*

**建议**：形容词 + 介词是固定搭配，必须逐一记忆。常见：

- interested **in**, proud **of**, afraid **of**, good **at**, responsible **for**, similar **to**, different **from**

---

### 1.7 现实应用 / 练习建议

1. **造"三明治"句**：每天造 5 个"副词 + 形容词 + 介词短语"结构的句子，如 *I'm really happy about my progress.*
2. **形容词卡片**：每个形容词配上它常用的后置介词，一起记。如：proud → of, tired → of/from。
3. **改写练习**：把简单句里的形容词扩展成完整 AdjP，感受信息量的变化。
  - *She is happy.* → *She is incredibly happy about her new job.*

### 二、副词短语（AdvP, Adverb Phrase）

### 2.1 是什么

**一句话定义：** 以副词为核心，整体用来修饰动词、形容词、其他副词或整个句子的短语。

> 副词短语就像形容词短语的"孪生兄弟"，只不过它不描述名词，而是描述**动作怎么发生**、**程度有多深**、**时间在哪里**。

---

### 2.2 核心结构公式

```
// 代码块
AdvP = (PreModifier) + Adverb HEAD + (PostModifier)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| PreModifier | 副词（修饰副词程度） | very, quite, much, far, even |
| Adverb HEAD | **核心副词** | quickly, soon, hard, well, often |
| PostModifier | 介词短语或比较结构（较少见） | enough + to do; than expected |

#### 三种基本形态

**① 单独副词**

```
// 代码块
[Adv]

```

- *She speaks quickly.*
- *He arrived early.*

**② 副词 + 副词（修饰程度）**

```
// 代码块
[Adv] + [Adv HEAD]

```

- *She speaks very quickly.*
- *He left quite suddenly.*
- *She performed remarkably well.*

**③ 副词 + enough + 不定式（表"足够…以至于"）**

```
// 代码块
[Adv HEAD] + enough + [InfP]

```

- *She spoke clearly enough [to be understood].*
- *He ran fast enough [to catch the bus].*

---

### 2.3 扩展方式

#### 扩展一：too + Adv + to do（太…而不能）

```
// 代码块
too + [Adv] + to + [V]

```

- *He drove too slowly to keep up with traffic.*
- *She spoke too quietly to be heard.*

#### 扩展二：比较结构

```
// 代码块
[Adv] + -er / more + [Adv] + than

```

- *She runs faster than her brother.*
- *He speaks more fluently than he writes.*

#### 扩展三：副词做句子修饰语（Sentence Adverbial）

整个 AdvP 放句首或句末，修饰整个句子的语气、态度：

- ***Frankly, I don't agree.***
- ***Surprisingly, no one was hurt.***
- ***Unfortunately, we missed the train.***

#### 扩展四：焦点副词（Focus Adverb）

强调句中特定成分：

- *I only saw her yesterday.* （only 是焦点副词）
- ***Even she couldn't solve it.***

---

### 2.4 例句（标注结构）

| 句子 | 结构分析 |
| --- | --- |
| She sings **beautifully**. | Adv HEAD only |
| He drives **very carefully**. | AdvP(very) + Adv(carefully) |
| She arrived **surprisingly early**. | AdvP(surprisingly) + Adv(early) |
| He spoke **clearly enough to be understood**. | Adv(clearly) + enough + InfP |
| **Honestly**, I have no idea. | Sentence AdvP（句子修饰语） |

---

### 2.5 与其他短语的关系

- **AdvP 修饰 VP**（最常见）：
  - *She quickly finished her homework.* → AdvP 修饰动词短语
- **AdvP 修饰 AdjP**：
  - *The result was surprisingly good.* → AdvP 修饰 AdjP
- **AdvP 修饰另一个 AdvP**：
  - *She sang very beautifully.* → very 修饰 beautifully
- **AdvP 做句子修饰语**：
  - *Fortunately, everyone survived.* → AdvP 在句子层面发挥作用
- **PP 常常充当 AdvP 的角色**：
  - *She arrived [at noon].* → PP 做时间状语，功能类似 AdvP

---

### 2.6 中国学习者常见错误

#### ❌ 错误1：副词位置放错（尤其是频率副词）

> ❌ *She goes always to school by bus.*
> ✅ *She always goes to school by bus.*

**规则**：频率副词（always, often, usually, never, sometimes）放在**助动词后、实义动词前**。

---

#### ❌ 错误2：hard 和 hardly 混淆

> ❌ *He works hardly.* （想说"他努力工作"）
> ✅ *He works hard.* （hard 做副词 = 努力地）

> ❌ *He hard sleeps.* （想说"他几乎不睡觉"）
> ✅ *He hardly sleeps.* （hardly = 几乎不）

**规则**：hard / late / near / high 等副词与加了 -ly 的版本意思完全不同。

---

#### ❌ 错误3：副词修饰名词（汉语思维迁移）

> ❌ *a very girl* / *a quickly boy*
> ✅ 副词不能直接修饰名词，只有形容词才能修饰名词

**规则**：副词修饰动词、形容词、副词或句子；名词由形容词修饰。

---

### 2.7 现实应用 / 练习建议

1. **日记扩展法**：写英文日记时，给每个动词加一个 AdvP，强迫自己描述"怎么做的"。
  - *I woke up.* → *I woke up surprisingly early this morning.*
2. **频率副词定位练习**：把 always/often/never/sometimes 放进 10 个不同句式，确保每次位置都对。
3. **对比练习**：hard/hardly, late/lately, near/nearly 各造 3 组对比句，彻底分清。

### 三、介词短语（PP, Prepositional Phrase）

### 3.1 是什么

**一句话定义：** 由介词开头、后跟名词性成分（NP/代词/从句等）构成的短语，表示位置、时间、方式、原因等关系。

> PP 是英语里**最高频的修饰工具**。几乎每个句子都有 PP，用来补充说明"在哪里、什么时候、怎样、为什么、跟谁"等信息。

---

### 3.2 核心结构公式

```
// 代码块
PP = Preposition + NP (Complement of Preposition)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| Preposition（介词） | **必须有**，是 PP 的核心功能词 | in, on, at, for, with, by, about, of, to, from |
| NP / Complement（补语） | 介词后的名词性成分 | the table, noon, her, what he said |

#### 基本形态

**① 介词 + 名词（最常见）**

```
// 代码块
[Prep] + [NP]

```

- *She sat [on the chair].*
- *The book is [about history].*
- *He arrived [at noon].*

**② 介词 + 代词**

```
// 代码块
[Prep] + [Pronoun]

```

- *He looked [at her].*
- *I did it [for him].*

**③ 介词 + -ing 动名词（NP 的一种）**

```
// 代码块
[Prep] + [Gerund Phrase]

```

- *She is good [at singing].*
- *He left [without saying goodbye].*
- *I'm interested [in learning Chinese].*

**④ 介词 + wh-从句 / that-从句**

```
// 代码块
[Prep] + [Clause]

```

- *I'm curious [about what he said].*
- *It depends [on whether you agree].*

---

### 3.3 扩展方式

#### 扩展一：PP 的 NP 补语本身是复杂 NP

```
// 代码块
in + [the old wooden house on the hill]

```

- *She lived in the old wooden house on the hill.* → PP 内嵌套复杂 NP

#### 扩展二：PP 嵌套 PP（PP 作为 NP 的后置修饰）

```
// 代码块
[Prep] + [NP [+ PP]]

```

- *He hid under [the table [in the kitchen]].* → 两个 PP 嵌套
- *The key is in [the box [on the shelf [in the basement]]].* → 三层嵌套

#### 扩展三：复合介词（Multi-word Prepositions）

```
// 代码块
in spite of / because of / in front of / as a result of / on behalf of

```

- *She went in spite of the rain.*
- *He was fired as a result of his behavior.*

#### 扩展四：PP 做后置定语（修饰名词）

```
// 代码块
NP + PP

```

- *the man [with the red hat]*
- *the girl [in the blue dress]*
- *a cup [of hot coffee]*

#### 扩展五：PP 做状语（修饰动词/句子）

- 时间：*She called [at midnight].*
- 地点：*They met [in Paris].*
- 方式：*He solved it [with great skill].*
- 原因：*She cried [out of joy].*

---

### 3.4 例句（标注结构）

| 句子 | 结构分析 |
| --- | --- |
| The cat is **on the mat**. | PP = on + NP(the mat)，做地点状语 |
| I left **without saying a word**. | PP = without + Gerund Phrase，做方式状语 |
| She's curious **about what happened**. | PP = about + wh-clause，做形容词补语 |
| The book **on the table** is mine. | PP 做后置定语，修饰 book |
| He succeeded **because of his hard work**. | PP（复合介词）做原因状语 |

---

### 3.5 与其他短语的关系

PP 是英语中最"万能"的短语，几乎能充当所有功能：

| 功能 | 例子 |
| --- | --- |
| **做状语**（修饰动词） | *She sang with passion.* |
| **做定语**（修饰名词，后置） | *the house on the hill* |
| **做表语**（系动词后） | *The key is on the table.* |
| **做形容词补语** | *proud of his work* |
| **做动词补语** | *put the book on the shelf* |
| **嵌入 NP** | *a friend of mine* |

PP 也常与其他短语**嵌套**：

- AdjP + PP：*afraid of the dark*
- VP + PP：*run away from the problem*
- NP + PP：*the king of England*

---

### 3.6 中国学习者常见错误

#### ❌ 错误1：漏掉冠词（NP 不完整）

> ❌ *She sat on chair.*
> ✅ *She sat on the chair.*

**规则**：介词后的 NP 通常需要限定词（a/the/my/this 等），除非是专有名词、不可数名词泛指或习惯表达（at school, in bed, by car）。

---

#### ❌ 错误2：介词选错（硬套汉语）

> ❌ *I will go to there.* （to 后不接 there）
> ✅ *I will go there.* / *I will go to that place.*

> ❌ *She is married with him.*
> ✅ *She is married to him.*

> ❌ *He is different than me.* （美式可接受，但正式英语）
> ✅ *He is different from me.*

---

#### ❌ 错误3：介词 + 动词（忘记用动名词）

> ❌ *I'm good at to speak English.*
> ✅ *I'm good at speaking English.*

**规则**：介词后接动词时，必须用动名词（-ing form），不能用不定式（to + V）。

例外：*except to do*、*but to do* 中的 but/except 可跟不定式。

---

### 3.7 现实应用 / 练习建议

1. **介词替换练习**：取一个简单句，依次换掉介词，观察意思变化。
  - *She sat on/by/near/in front of/behind the table.*
2. **介词搭配本**：专门记录"动词/形容词 + 介词"固定搭配，每周 10 个。
  - consist of, result in, rely on, congratulate sb on, apologize to sb for...
3. **拆句练习**：读英文文章时，圈出所有 PP，标注它们在句子里的功能（状语/定语/补语）。

### 四、不定式短语（Infinitive Phrase）

### 4.1 是什么

**一句话定义：** 以"to + 动词原形"开头，后面跟动词的宾语、补语或修饰语，整体可以做名词、形容词或副词用的短语。

> 不定式短语是英语里最灵活的结构之一——同一个 *to do* 结构，放在不同位置可以做主语、宾语、定语、目的状语……简直是"变形金刚"。

---

### 4.2 核心结构公式

```
// 代码块
Infinitive Phrase = to + V (+ Object) (+ Complement/Modifier)

```

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| to | 不定式标记（有时省略） | to |
| V（动词原形） | **必须有**，是短语核心 | go, eat, finish, help, understand |
| Object（宾语） | 动词的直接/间接宾语 | the book, him, me |
| Complement / Modifier | 补充说明动词的成分 | quickly, in time, about this |

#### 基本形态

**① to + V（最简）**

```
// 代码块
[to] + [V]

```

- *She wants to leave.*
- *He decided to stay.*

**② to + V + 宾语**

```
// 代码块
[to] + [V] + [NP]

```

- *She wants to read [the book].*
- *He offered to help [us].*

**③ to + V + 补语（形容词/名词）**

```
// 代码块
[to] + [V] + [AdjP/NP]

```

- *He seems to be .*
- *She wants to become [a doctor].*

**④ to + V + 状语（副词/PP）**

```
// 代码块
[to] + [V] + [AdvP/PP]

```

- *She ran to catch [the bus].* → to + V + PP（目的）
- *He studied hard to pass [the exam].*

**⑤ 完整形态：to + V + 宾语 + 修饰语**

```
// 代码块
[to] + [V] + [NP] + [Modifier]

```

- *She promised to finish [the project] [by Friday].*
- *He wants to read [the report] [carefully].*

---

### 4.3 扩展方式

#### 扩展一：不定式短语做主语（形式主语 it）

```
// 代码块
It + be + Adj/NP + [to + V ...]

```

- *It is important to stay calm.*
- *It took me an hour to finish the assignment.*

注：直接用 *To + V... is...* 也对，但较正式：

- ***To err is human; to forgive, divine.***

---

#### 扩展二：不定式短语做宾语

```
// 代码块
[V] + [to + V ...]

```

只有特定动词后可接不定式（want, hope, decide, refuse, plan, promise, tend 等）：

- *She decided to quit her job.*
- *I hope to see you soon.*

---

#### 扩展三：不定式短语做定语（后置，修饰名词）

```
// 代码块
[NP] + [to + V ...]

```

- *I have a lot of work to do.*
- *She is the first person to arrive.*
- *He has no money to spend.*

---

#### 扩展四：不定式短语做状语（目的/结果/原因）

```
// 代码块
[Main Clause] + [to + V ...]  （目的）
[Main Clause] + only to + V  （令人失望的结果）
[Adj] + to + V                （原因/情感来源）

```

- *She studied hard to pass the exam.* → 目的
- *He worked for hours, only to fail.* → 令人沮丧的结果
- *I'm happy to help you.* → 原因/态度

---

#### 扩展五：带逻辑主语的不定式（for + NP + to + V）

```
// 代码块
for + [NP] + to + [V ...]

```

- *It is important for you to understand this.*
- *It's time for us to leave.*
- ***For him to say that is very rude.***

---

#### 扩展六：不带 to 的不定式（裸不定式 / Bare Infinitive）

某些结构中 to 被省略：

- 情态动词后：*She can swim.*
- 使役动词 make/let/have 后：*She made him apologize.*
- 感官动词 see/hear/watch/feel + 宾语后：*I saw her run across the street.*

---

### 4.4 例句（标注结构）

| 句子 | 功能 | 结构分析 |
| --- | --- | --- |
| **To learn English** is my goal. | 主语 | InfP = to learn + NP(English) |
| She wants **to become a teacher**. | 宾语 | InfP = to become + NP(a teacher) |
| I need something **to eat**. | 定语（修饰 something） | InfP = to eat |
| He called **to ask for help**. | 目的状语 | InfP = to ask + PP(for help) |
| It is difficult **for her to decide**. | 形式主语结构 | for + NP + InfP |
| She was sad **to hear the news**. | 原因状语 | InfP = to hear + NP |

---

### 4.5 与其他短语的关系

- **不定式 vs. 动名词（Gerund）**：很多动词后接不定式或动名词意思不同：
  - *I stopped to smoke.* （停下来去抽烟 → 目的）
  - *I stopped smoking.* （戒烟了 → 动名词做宾语）
  - *She remembered to lock the door.* （记得要去锁）
  - *She remembered locking the door.* （记得曾经锁过）
- **不定式短语内嵌 PP**：
  - *to work hard for the team*
- **不定式短语内嵌 NP + AdjP**：
  - *to find the task surprisingly easy*
- **不定式短语嵌入 NP 做后置定语**：
  - *the ability to adapt quickly*

---

### 4.6 中国学习者常见错误

#### ❌ 错误1：不定式 vs. 动名词混用

> ❌ *I enjoy to play basketball.*
> ✅ *I enjoy playing basketball.*

**规则**：enjoy, avoid, finish, suggest, recommend, mind, miss, keep, consider 等动词后只接动名词，不接不定式。

常见只接不定式的动词：want, hope, decide, refuse, plan, promise, tend, manage, fail, agree。

---

#### ❌ 错误2：使役/感官动词后加 to

> ❌ *She made him to apologize.*
> ✅ *She made him apologize.*（裸不定式）

> ❌ *I saw her to cross the road.*
> ✅ *I saw her cross / crossing the road.*

**规则**：make, let, have, see, hear, watch, feel + 宾语后用裸不定式（主动进行时可用 -ing）。

---

#### ❌ 错误3：不定式短语的逻辑主语混淆（悬挂不定式）

> ❌ *To improve my English, practice is important.*
> ✅ *To improve my English, I need to practice.*

**规则**：不定式短语的逻辑主语必须与主句主语一致。上面错误句的意思变成"为了让练习提升我的英语……"，逻辑混乱。

---

### 4.7 现实应用 / 练习建议

1. **动词分类表**：制作"只接不定式 / 只接动名词 / 两者皆可"三栏表，反复测试自己。
2. **目的状语替换**：把汉语"为了…"的句子翻译成英语，练习用 *in order to / so as to / to + V* 表达目的。
3. **句型转换练习**：把主语从句换成形式主语结构：
  - *To finish on time is hard.* → *It is hard to finish on time.*
4. **阅读标注**：读英文文章时，圈出所有不定式短语，判断它们做的是主语、宾语、定语还是状语。

## 1. 分词短语（Participial Phrase）

### 是什么

> 用动词的分词形式（现在分词 -ing 或过去分词 -ed/-en）领头的短语，充当形容词或副词，修饰名词或整个句子。

简单说：**"带着 -ing 或 -ed 的动词短语，用来描述人或事物的状态"**。

---

### 核心结构

#### 现在分词短语（Present Participial Phrase）

```
// 代码块
公式：V-ing + (宾语/状语) → 修饰名词 或 作状语

```

表示"主动进行"的动作或状态，与被修饰词存在**主动关系**。

#### 过去分词短语（Past Participial Phrase）

```
// 代码块
公式：V-ed/V-en + (宾语/状语) → 修饰名词 或 作状语

```

表示"被动完成"的动作或状态，与被修饰词存在**被动关系**。

#### 独立分词短语（Absolute Participial Phrase）

```
// 代码块
公式：名词/代词 + V-ing/V-ed → 作状语（有自己的逻辑主语）

```

分词短语有独立的主语，不依赖主句主语。

---

### 详细说明

#### 1.1 现在分词短语

**前置修饰名词**（放在名词前）：

- 通常是单个分词
- 例：*a running dog*（一只跑着的狗），*the rising sun*（升起的太阳）

**后置修饰名词**（放在名词后）：

- 分词短语较长时放后面
- 例：*the man standing by the door*（站在门边的那个人）

**作状语**（修饰整句，说明时间/原因/结果/条件/方式）：

- 分词短语的逻辑主语 = 主句主语
- 例：*Walking down the street, I saw an old friend.*（走在街上，我看到了一位老朋友。）

#### 1.2 过去分词短语

**前置修饰**：

- 例：*a broken window*（一扇破窗），*frozen food*（冷冻食品）

**后置修饰**：

- 例：*the house built in 1990*（1990年建造的那栋房子）

**作状语**：

- 例：*Exhausted by the long journey, she fell asleep immediately.*（被漫长旅途弄得精疲力竭，她立刻睡着了。）

#### 1.3 独立分词短语

逻辑主语与主句主语**不同**，需在分词前加名词/代词：

- 例：*Weather permitting, we'll have a picnic.*（天气允许的话，我们就去野餐。）
- 例：*The sun having set, we decided to go home.*（太阳下山后，我们决定回家。）

---

### 例句

#### 现在分词短语例句

| 例句 | 说明 |
| --- | --- |
| **Smiling happily**, she accepted the award. | 状语，修饰整句（方式） |
| **Hearing the news**, he burst into tears. | 状语，表原因 |
| The dog **wagging its tail** ran toward me. | 后置修饰 the dog |
| **Not knowing what to say**, I stayed silent. | 否定式分词短语 |
| She sat there **reading a novel**. | 伴随状语 |

#### 过去分词短语例句

| 例句 | 说明 |
| --- | --- |
| **Surprised by the result**, everyone applauded. | 状语，表原因 |
| The letter **written in French** was hard to read. | 后置修饰 the letter |
| **Deeply moved**, she couldn't speak a word. | 状语，表原因/状态 |
| **Given more time**, I could do a better job. | 状语，表条件 |
| He walked away, **head bowed in shame**. | 独立分词结构 |

---

### 中国学习者常见错误

#### ❌ 错误1：悬垂分词（Dangling Participle）— 分词的逻辑主语与主句主语不一致

> ❌ *Walking down the street, a dog bit me.*
> （"一条狗"并不是"走在街上"的主体，逻辑混乱）

> ✅ *Walking down the street, I was bitten by a dog.*
> 或：*While I was walking down the street, a dog bit me.*

---

#### ❌ 错误2：混淆主动/被动——用错 -ing 或 -ed

> ❌ *The interesting students answered the question.*（想表达"感兴趣的"学生）
> ✅ *The interested students answered the question.*
> （interested = 感兴趣的学生；interesting = 令人感兴趣的内容）

---

#### ❌ 错误3：位置错误——分词短语放错位置导致修饰歧义

> ❌ *I saw a man wearing a red hat at the station yesterday.*
> （可能被理解为：我昨天在车站，穿红帽子的我，看到了一个男人）

> ✅ 通过上下文确保分词短语紧靠被修饰词。

---

### 与其他概念的关系

- **介词短语**：不含动词，分词短语含动词分词形式，功能有重叠（均可作状语/后置定语）
- **不定式短语**：to + V，也可作定语/状语；分词短语强调"进行/完成"，不定式强调"目的/将来"
- **名词短语**：分词短语可嵌入名词短语中作后置定语，形成嵌套结构
- **独立主格结构**：独立分词短语是独立主格的一种形式

## 2. 固定搭配与习语（Collocations & Idioms）

### 是什么

> **固定搭配（Collocations）**：两个或多个词习惯性地一起出现，虽然可从字面理解，但只有这种组合才地道，换其他词就"不自然"。
> **习语（Idioms）**：一组词放在一起，整体意义**无法从各个单词字面意思推断**出来，必须整体记忆。

简单说：**搭配 = 哪些词喜欢"在一起"；习语 = 字面和实际意思完全两回事**。

---

### 核心结构/规则

#### 2.1 固定搭配的类型

```
// 代码块
动词 + 名词：make a decision, take a risk, give advice
形容词 + 名词：strong coffee, heavy rain, deep sleep
名词 + 动词：time flies, prices rise
副词 + 形容词：deeply moved, highly recommended
动词 + 介词：depend on, look forward to, result in
名词 + 介词：reason for, solution to, attitude toward

```

**核心规律**：搭配是"约定俗成"的，不能随意替换同义词。

- ✅ *make a decision* ≠ ❌ *do a decision*
- ✅ *heavy rain* ≠ ❌ *strong rain*（大雨）

#### 2.2 习语的结构特点

```
// 代码块
动词短语习语：kick the bucket（死）, hit the sack（去睡觉）
介词短语习语：by and large（总体上）, out of the blue（突然）
比较结构习语：as cool as a cucumber（非常冷静）
身体部位习语：cost an arm and a leg（非常贵）
动物习语：let the cat out of the bag（泄露秘密）
颜色习语：see red（暴怒）, feel blue（忧郁）
数字习语：on cloud nine（非常高兴）

```

---

### 例句

#### 固定搭配例句

| 搭配 | 例句 |
| --- | --- |
| make progress | *She has made great progress in her studies.* |
| take responsibility | *He refused to take responsibility for his mistake.* |
| pay attention | *Please pay attention to the road signs.* |
| raise awareness | *The campaign aimed to raise awareness about climate change.* |
| reach a compromise | *After long negotiations, they finally reached a compromise.* |

#### 习语例句

| 习语 | 意思 | 例句 |
| --- | --- | --- |
| bite the bullet | 咬紧牙关，硬撑 | *I just had to bite the bullet and go to the dentist.* |
| spill the beans | 泄露秘密 | *Don't spill the beans about the surprise party.* |
| hit the nail on the head | 说到点子上 | *You really hit the nail on the head with that analysis.* |
| under the weather | 身体不适 | *I'm feeling a bit under the weather today.* |
| burn bridges | 断绝关系 | *Quitting like that really burned her bridges at the company.* |

---

### 中国学习者常见错误

#### ❌ 错误1：用中文思维直译搭配

> ❌ *do a decision*（中文：做一个决定）
> ✅ *make a decision*

> ❌ *open the light*（中文：开灯）
> ✅ *turn on the light*

---

#### ❌ 错误2：混淆近义词搭配

> ❌ *strong rain*（strong 和 rain 不搭配）
> ✅ *heavy rain*

> ❌ *make homework*
> ✅ *do homework*（do vs. make：do 用于任务/活动；make 用于创造/产生）

---

#### ❌ 错误3：望文生义理解习语

> ❌ 看到 *it's raining cats and dogs* 以为"猫猫狗狗从天而降"
> ✅ 正确理解：倾盆大雨

> ❌ 看到 *break a leg* 以为"折断一条腿"
> ✅ 正确理解：祝你好运！（演出/表演前的祝福语）

---

### 与其他概念的关系

- **短语动词（Phrasal Verbs）**：习语的一种子集，由动词+介词/副词构成，整体意思常有引申义
- **名词短语**：许多固定搭配以名词短语形式出现（如 *a close call*，千钧一发）
- **高频搭配词表**：本节理论基础，词表是大量固定搭配的整理汇总
- **中英差异**：英语搭配逻辑与汉语常有出入，是学习难点

## 3. 短语在句中的功能

### 是什么

> 短语不是孤立存在的，它在句子里充当**一个具体的语法成分**，就像汉语里的主语、谓语、宾语、定语、状语一样。

简单说：**同一类短语，放在不同位置，就扮演不同角色**。

---

### 核心结构/规则

英语句子的七大成分，短语都可以充当：

| 句子成分 | 英文 | 核心问题 | 常用短语类型 |
| --- | --- | --- | --- |
| 主语 | Subject | 谁/什么做这件事？ | 名词短语、不定式短语、动名词短语 |
| 谓语 | Predicate | 做了什么？ | 动词短语（含助动词） |
| 宾语 | Object | 做了什么的对象？ | 名词短语、不定式短语、动名词短语 |
| 定语 | Attribute | 修饰哪个名词？ | 形容词短语、介词短语、分词短语、不定式短语 |
| 状语 | Adverbial | 在哪/何时/如何/为何？ | 介词短语、副词短语、分词短语、不定式短语 |
| 表语 | Predicative | 主语是什么/怎样？ | 形容词短语、名词短语、介词短语 |
| 同位语 | Appositive | 进一步解释前面的名词 | 名词短语、不定式短语 |

---

### 各成分详细说明 + 例句

#### 3.1 主语（Subject）

短语作主语时，整个短语是句子的核心话题。

```
// 代码块
名词短语作主语：
→ [The tall man in the blue coat] is my uncle.
（那个穿蓝色外套的高个子男人是我叔叔。）

不定式短语作主语：
→ [To learn a new language] takes years of practice.
（学一门新语言需要多年练习。）

动名词短语作主语：
→ [Running every morning] keeps me healthy.
（每天早晨跑步让我保持健康。）

```

---

#### 3.2 谓语（Predicate）

动词短语（含助动词）构成谓语，是句子的核心动作。

```
// 代码块
→ She [has been studying] for three hours.（现在完成进行时）
→ They [will be informed] as soon as possible.（被动 + 将来时）
→ He [might have left] already.（情态 + 完成时）

```

---

#### 3.3 宾语（Object）

动词后面接受动作的那个成分。

```
// 代码块
名词短语作宾语：
→ I bought [a beautiful red dress].

不定式短语作宾语：
→ She wants [to become a doctor].

动名词短语作宾语：
→ He enjoys [playing chess with his grandfather].

that从句（名词性从句）作宾语：
→ I believe [that honesty is the best policy].

```

---

#### 3.4 定语（Attribute）

修饰名词，回答"什么样的"。

```
// 代码块
形容词短语作定语（前置）：
→ a [very expensive] car

介词短语作定语（后置）：
→ the book [on the shelf]（架子上那本书）

分词短语作定语（后置）：
→ the woman [carrying a red umbrella]（拿着红伞的女人）

不定式短语作定语（后置）：
→ the first person [to arrive]（第一个到达的人）

```

---

#### 3.5 状语（Adverbial）

修饰动词、形容词或整句，说明时间、地点、方式、原因、目的、结果、条件、让步。

```
// 代码块
介词短语作状语（地点）：
→ She lives [in a small town].

介词短语作状语（时间）：
→ We'll meet [at noon].

分词短语作状语（原因）：
→ [Feeling tired], he went to bed early.

不定式短语作状语（目的）：
→ She worked hard [to pass the exam].

副词短语作状语（方式）：
→ He spoke [very softly].

```

---

#### 3.6 表语（Predicative）

在系动词（be/seem/look/feel/become等）后，描述主语的状态或性质。

```
// 代码块
形容词短语作表语：
→ The soup smells [absolutely delicious].

名词短语作表语：
→ She became [the first female president].

介词短语作表语：
→ The keys are [on the table].

不定式短语作表语：
→ My plan is [to travel around the world].

```

---

#### 3.7 同位语（Appositive）

紧跟在名词后面，进一步解释说明该名词，二者指同一事物。

```
// 代码块
名词短语作同位语：
→ My sister, [a talented musician], won the competition.
（我姐姐，一位有才华的音乐家，赢得了比赛。）

不定式短语作同位语：
→ His dream, [to become an astronaut], drove him forward.

that从句作同位语：
→ The news [that he had passed the exam] spread quickly.

```

---

### 中国学习者常见错误

#### ❌ 错误1：同位语与定语从句混淆

> ❌ *The news that he told me surprised everyone.*（这是定语从句，修饰 news 的内容是"他告诉我的新闻"）
> 与 *The news that he had passed surprised everyone.* 的区别：
> ✅ 同位语从句：that 后面是对 news 内容的解释（he had passed = news 的内容）
> ✅ 定语从句：that 在从句中作成分（he told me **that** → 这里 that 作宾语）

---

#### ❌ 错误2：不定式/动名词作主语时忘记用形式主语

> ❌ *To learn English well is very important.* （语法正确，但书面语中显得头重脚轻）
> ✅ *It is very important to learn English well.*（用 it 作形式主语更自然）

---

#### ❌ 错误3：状语位置放错

> ❌ *I every day go to school by bike.*（受中文语序影响）
> ✅ *I go to school by bike every day.*（频率副词通常放句末或句首，不插在主谓之间）

---

### 与其他概念的关系

- **短语嵌套结构**：一个短语在句中充当某成分时，内部可能嵌套其他短语
- **分词短语**：主要充当定语和状语
- **不定式短语**：功能最多样，可充当主/宾/定/状/表语
- **名词短语**：主要充当主/宾/表/同位语

---

## 4. 短语嵌套结构（Nested Phrases）

### 是什么

> 一个短语的内部，还包含着另一个短语（甚至多层），就像俄罗斯套娃一样，一层套一层。

简单说：**短语里面还有短语，大短语套小短语，层层嵌套形成复杂结构**。

---

### 核心结构/规则

#### 基本嵌套模式

```
// 代码块
最简单的嵌套：
[名词短语] = 限定词 + (形容词短语) + 名词 + (介词短语/分词短语)
→ [the + [very tall] + man + [with a beard]]

```

#### 常见嵌套类型

**类型1：名词短语内嵌介词短语**

```
// 代码块
NP → Det + Adj + N + PP
→ [the old house [at the end [of the street]]]
   └── NP ─────────────────────────────────
           └── PP ─────────────────────────
                    └── PP ──────────────

```

三层嵌套：the old house → at the end → of the street

**类型2：名词短语内嵌分词短语**

```
// 代码块
NP → Det + N + PartP
→ [the woman [sitting [in the corner [of the café]]]]

```

**类型3：动词短语内嵌名词短语和介词短语**

```
// 代码块
VP → V + NP + PP
→ [put [the red book] [on [the second shelf [of the bookcase]]]]

```

**类型4：形容词短语内嵌介词短语**

```
// 代码块
AP → Adv + Adj + PP
→ [very fond [of classical music]]
→ [deeply interested [in the history [of ancient Rome]]]

```

**类型5：不定式短语内嵌名词短语和介词短语**

```
// 代码块
InfP → to + V + NP + PP
→ [to send [a formal apology letter] [to the committee]]

```

---

### 嵌套深度分析示例

分析句子：*The tall woman in the blue dress standing near the window smiled.*

```
// 代码块
层级分解：
主语（名词短语）：[The tall woman in the blue dress standing near the window]
  ├── The tall woman（核心名词短语）
  ├── in the blue dress（介词短语，修饰 woman）
  │     └── the blue dress（介词的宾语，名词短语）
  └── standing near the window（分词短语，修饰 woman）
        └── near the window（介词短语，修饰 standing）
谓语：smiled

```

---

### 例句

| 例句 | 嵌套结构说明 |
| --- | --- |
| *I met [a friend [of mine [from college [in Beijing]]]].* | 四层名词/介词嵌套 |
| *She is [very proud [of [her son's achievement]]].* | 形容词短语套介词短语套名词短语 |
| *[Knowing [that the meeting [scheduled for Monday] had been cancelled]], he relaxed.* | 分词短语套that从句套分词短语 |
| *The plan [to build [a new bridge [across the river [near the old town]]]] was approved.* | 不定式套名词短语套介词短语（三层） |
| *He decided [to try [to persuade [the committee [in charge of funding]] to approve [the proposal]]].* | 多层嵌套：不定式套不定式 |

---

### 中国学习者常见错误

#### ❌ 错误1：嵌套过深导致主谓失控——忘记主句谓语

> ❌ *The man who came to the party last night that my friend had organized in the big hall.*
> （有主语，但没有主句谓语！这是一个不完整的句子）

> ✅ *The man who came to the party that my friend had organized in the big hall was my old teacher.*

---

#### ❌ 错误2：修饰语远离中心词，造成歧义

> ❌ *I found a wallet walking down the street.*
> （看起来好像"钱包"在走路）

> ✅ *Walking down the street, I found a wallet.*

---

#### ❌ 错误3：嵌套层级不清，后置修饰语搭错对象

> ❌ *She bought a dress in the shop which was very cheap.*
> （which 指的是 shop 还是 dress？有歧义）

> ✅ *She bought a dress which was very cheap in the shop.*
> 或：*In the shop, she bought a very cheap dress.*

---

### 与其他概念的关系

- **所有短语类型**：都可以作为嵌套的组成单元
- **短语功能**：嵌套短语在句中整体仍然充当某一语法成分
- **中英差异**：英语后置修饰嵌套多；汉语前置修饰嵌套多，结构分布不同
- **分词短语**：常作为名词短语内的后置嵌套成分

---

## 5. 中英短语结构差异

### 是什么

> 中文短语和英文短语在**修饰语的位置、中心词的位置、结构顺序**上存在系统性差异，这是中国学生学英语最大的"思维迁移"障碍之一。

---

### 核心差异对比

#### 5.1 修饰语位置：前置 vs. 后置

| 维度 | 汉语 | 英语 |
| --- | --- | --- |
| 定语位置 | **一律前置**，无论长短 | **短前置，长后置** |
| 定语从句 | 用"的"字结构，放名词前 | 放名词后（关系从句） |
| 介词短语作定语 | 通常转化为"的"前置 | 直接后置 |

**示例：**

| 中文 | 英文 |
| --- | --- |
| 那个**昨天下午在图书馆里看书的**男孩 | the boy **who was reading in the library yesterday afternoon** |
| **我朋友从北京带来的**礼物 | the gift **brought by my friend from Beijing** |
| **装在红色盒子里的**苹果 | the apple **in the red box** |

**规律**：汉语所有修饰成分都在名词**前面**；英语超过3-4个词的修饰语通常移到名词**后面**。

---

#### 5.2 中心词位置

| 语言 | 结构特点 |
| --- | --- |
| 汉语 | **修饰语→中心词**（定语→名词；状语→动词） |
| 英语 | 名词短语基本同汉语（前定语+名词），但长定语后置 |

**示例：**

```
// 代码块
汉语：用友好和耐心的方式（状语在前）
英语：in a friendly and patient manner（介词在前，修饰词在后）

汉语：十分漂亮的一件红色连衣裙
英语：a very beautiful red dress（限定词+副词+形容词+名词，与汉语类似）

```

---

#### 5.3 动词短语结构差异

| 维度 | 汉语 | 英语 |
| --- | --- | --- |
| 时态 | 无形态变化，靠时间词和语境 | 动词本身变形（过去/现在/完成） |
| 被动 | "被"字句，或不标记（零形式被动） | 助动词 be + 过去分词 |
| 连续动作 | 动词并列（走出去拿起来翻一翻） | 用分词/不定式/从句表示关系 |
| 趋向补语 | 走进来、拿出去、放下来 | 短语动词 come in, take out, put down |

**示例：**

```
// 代码块
汉语：他走进屋子拿起书看了看。（四个动词并列）
英语：He walked into the room, picked up the book, and flipped through it.
（用逗号和连词整合，不能简单并列四个动词）

```

---

#### 5.4 介词短语差异

| 维度 | 汉语 | 英语 |
| --- | --- | --- |
| 介词位置 | 通常在动词**前**（"在桌上放着"→介词短语前置） | 通常在动词**后**（"is on the table"→介词短语后置） |
| 工具/方式 | "用...""以..."前置 | with/by/in 等后置 |

```
// 代码块
汉语：他用钢笔写了一封信。（"用钢笔"前置）
英语：He wrote a letter with a pen.（with a pen 后置）

```

---

#### 5.5 数量结构差异

```
// 代码块
汉语：三本书 / 一杯水 / 两只鸟
      数词 + 量词 + 名词

英语：three books / a glass of water / two birds
      数词 + 名词（可数直接加s；不可数用"a ... of"结构）

```

**重要差异**：英语名词有可数/不可数之分，汉语没有（汉语所有名词都靠量词区分）。

---

#### 5.6 否定结构差异

```
// 代码块
汉语：我不是很喜欢。（否定词在谓语前）
英语：I don't like it very much.（借助助动词 don't）

汉语：没有人知道。
英语：Nobody knows. / No one knows.（否定移入主语）
     或：Everybody doesn't know.（较少用）

```

---

#### 5.7 比较结构差异

```
// 代码块
汉语：他比我高。（比 + 比较对象 + 形容词）
英语：He is taller than me.（形容词比较级 + than）

汉语：他没有我高。
英语：He is not as tall as me.（as ... as 结构）

汉语：越来越好
英语：better and better（比较级 + and + 比较级）

```

---

### 系统性差异总结表

| 结构类型 | 汉语规律 | 英语规律 |
| --- | --- | --- |
| 定语位置 | 全部前置（"的"字短语） | 短前置，长后置 |
| 状语位置 | 多前置（在...上，用...） | 多后置（句末） |
| 时间状语 | 常放句首或句中（昨天我去了...） | 常放句末（I went ... yesterday.） |
| 动词时态 | 无变化，靠时间词 | 动词本身变形 |
| 被动语态 | "被"字或零形式 | be + V-ed |
| 可数/不可数 | 无区别，靠量词 | 有严格区别 |
| 比较结构 | 比 + 对象 + 形容词 | 形容词-er + than |
| 否定位置 | 否定词直接加在动词前 | 借助助动词 do/be/have |

---

### 中国学习者常见错误（由差异导致）

#### ❌ 错误1：把长定语前置（套中文结构）

> ❌ *the yesterday afternoon in the library reading a novel boy*
> ✅ *the boy who was reading a novel in the library yesterday afternoon*

---

#### ❌ 错误2：介词短语前置（受汉语"在...上放着"影响）

> ❌ *On the table has a book.*（中文思维：桌子上有一本书）
> ✅ *There is a book on the table.*

---

#### ❌ 错误3：忽略名词可数/不可数，直接加量词套入

> ❌ *a furniture*（furniture 不可数）
> ✅ *a piece of furniture*

> ❌ *many informations*
> ✅ *much information* 或 *many pieces of information*

---

### 与其他概念的关系

- **嵌套结构**：英语后置嵌套是中英差异的核心体现
- **分词短语**：英语用分词后置修饰，汉语用"的"字前置
- **介词短语**：是中英位置差异最突出的短语类型
- **固定搭配**：许多搭配差异直接来自中英结构不同

### 附录：搭配学习建议

#### 为什么要学搭配？

- 语法正确但搭配错误的句子听起来很"外国腔"
- 母语者不是从规则推导出搭配，而是通过大量输入"感受"到什么搭配自然

#### 学习技巧

1. **不要单词单独记**：永远把单词放在搭配里记（不是记 *make*，而是记 *make a decision / make a mistake*）
2. **语料库验证**：不确定某个搭配是否自然，可查 COCA（美国英语语料库）或 BNC
3. **造句输出**：每学一个搭配，造一个关于自己生活的例句，记忆更深
4. **分类记忆**：同一动词的所有搭配放一起记（make 系列、take 系列）
5. **注意中英差异**：遇到跟中文不同的搭配（如 *heavy rain* 不是 *strong rain*），专门标记

## 专题：三词短语动词与介词及物化

### 什么是三词短语动词？

英语短语动词中有一类特殊结构：**动词 + 副词小品词 + 介词**，合称"三词短语动词"（Three-part Phrasal Verbs）。它的形成逻辑是：

1. **两词短语动词**（动词 + 副词）本身是不及物的，不带宾语。
  - *cut back*（削减，不及物）：*We need to cut back.*
  - *look forward*（向前看，字面义，不及物）
  - *put up*（承受，不及物）：*How much can you put up?*
2. **加上介词后变成及物**，介词后面必须接宾语（NP），整个结构不可分离。
  - *cut back on* → *cut back on sugar*（减少糖的摄入）
  - *look forward to* → *look forward to the trip*（期待这次旅行）
  - *put up with* → *put up with the noise*（忍受噪音）

这种"副词小品词负责改变动词语义，介词负责引入宾语"的机制，使三词短语动词成为英语中语义最丰富、也最难掌握的结构之一。**三词短语动词永远不可分离——宾语只能放在最后。**

### 学习建议

- **不可分离原则**：三词短语动词的三部分必须连在一起，宾语放最后。❌ *put the noise up with* → ✅ *put up with the noise*
- **to 是介词不是不定式标记**：*look forward to doing*、*get used to doing*——这里的 to 后面接动名词（-ing），不是不定式。
- **分组记忆**：按语义主题分组（表"忍受"：put up with / live with / bear with；表"追赶"：keep up with / catch up with），记一组比单个记更高效。
