## 做过哪些检查和处理

- 下载了 12 个字幕 ZIP：11 个初选包，加一份完整第三季替换包。全部通过 ZIP CRC 检查；下载大小、SHA-256、来源页和直链登记在 [资料 manifest](../../materials/downloads-manifest.json)。TVmaze 目录快照也登记了来源和哈希。
- 首个第三季包只有 23 集，并且 S03E04 有未编号、时间码不规范的问题，标为未选用；保留原下载文件，实际输出整季来自替换包。
- 逐文件按季集标签映射到目录，核对覆盖集合，检测同集重复和不同集间完全相同的文件。没有发现选入文件哈希重复；这不是逐集内容身份的音视频核验。
- **62 份来源文件使用旧西文编码**；整理版统一为 UTF-8 和 LF。**43 份存在字幕条目内部的冗余空行**，整理时收拢空行，使条目边界正常；对白、时间码、原编号、字幕组署名和声音说明保留。原始字节始终可从 ZIP 回查。
- 整理后合计 **136,322 条带时间码字幕**，约 **9.64 MB**。每份至少有 100 条可解析字幕；全部通过英文常用词比例筛查，未出现时间码起点倒退。抽读仍不能替代逐集听校。

未对照用户的视频检查同步，也未逐句确认听写准确性。来源混有 Blu-ray、HDTV、WEB-DL、DVDRip 等版本；用于播放时还需匹配视频版本。SDH 声音说明和上传者推广内容在原件中保留，后续提取 chunks 时应识别并排除非对白。

## 如何重建或查出处

```bash
# 从 english/ 项目目录执行；使用已下载原件，不访问网络
python3 references/build_modern_family_subtitles.py
```

[逐文件索引](../../references/subtitles/modern-family-index.json)记录每个输出文件的季集、剧集标题、条数、哈希、来源编码、来源页、ZIP 地址、原 ZIP 成员名和成员哈希。脚本只做编码及字幕空行整理，不翻译、改写台词或生成缺失对白。

字幕是社区上传资料，未发现明确开放许可，仅本地个人学习，不再分发。TVmaze 剧集元数据另按其 [CC BY-SA API 许可](https://www.tvmaze.com/api#licensing)使用并保留署名；元数据许可不覆盖字幕正文。原始 ZIP 与 SRT 留在本机、不进入 Git，仓库仅保存来源、索引和处理脚本。
