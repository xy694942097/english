# 第一版学习闭环实现计划

依据 learning-workbench.md 与用户“开始吧”执行。单机、SQLite，现有Markdown继续为教材来源。

- [x] Store模块：类型化知识点、教材关联、理解/表达进度、学习事件、幂等与撤销、导入候选、数据库备份导出。
- [x] 提取现有48词与主要搭配，保留正文、出处和稳定标识；重复扫描不重置用户进度。
- [x] 服务接口：查询、学习/复习/撤销、预览和确认录入；复用现有本机鉴权。生成候选独立于正式知识。
- [x] 页面：知识库搜索筛选、条目详情与学习按钮、到期队列与自评、录入候选、中文情境练习；保留阅读与对话。
- [x] 教学接入：条目与复习回答可传给老师；原答及自评入库，不以AI回复或生成量标记掌握。
- [x] 验证：隔离测试数据库，覆盖重启保持、两种模式独立、到期、失败重学、重复提交、撤销、去重、备份；浏览器验证完整操作后更新正式本机服务。

调度规则v1为可解释的启发式：首次学习次日；忘了10分钟后，费力按较短间隔，顺利按1/3/7/14/30/60天梯度；不宣传最优算法。到期队列在网页中显示，本轮不设置系统通知。

导入支持每行一个条目、可附制表符/中文分隔符释义；未提供上下文的词不自动认定唯一义项。可用现有Codex生成候选释义，再核对保存。整书解析与外部词典大规模授权导入留给后续阶段，不伪装为已完成。
