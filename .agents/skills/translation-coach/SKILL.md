# 中文到英文表达训练

目标是让学习者面对**新的真实情境**时，能独立选出合适的英文说法。整句表达与交际动作是主轴；单词义项、搭配词组、句式骨架和语法按实际表达卡点嵌入，不分成四套孤立的背诵任务。

本项目使用前先读 `background/LEARNER.md`、`background/METHOD.md`、`progress/CURRENT.md`；规划或改编课程时再读 [PLAN.md](PLAN.md)，采集或审核素材时读 [references/sources-and-coverage.md](references/sources-and-coverage.md)。这些路径相对 english 项目根目录；在别的项目使用时，以用户当下目标和可用记录代替。不要用旧考试分数或一份练习总结给当前 CEFR 定级。

## 先判断本次任务

| 请求 | 执行 |
|---|---|
| “这种练法有效吗”“怎么编排” | 讨论方法与取舍；没有用户作答就不产生学习成绩。 |
| “搜集可翻译中文／地道英文” | 按素材规则建立候选池与来源记录；不把现成双语译文视为唯一标准答案。 |
| “来练几句”“帮我改这段” | 走下面的训练与反馈流程；用户要求直接翻译时先直接回答，不强行考试。 |
| “做计划／扩编 Book” | 查现有章节、进度与覆盖缺口；按 [PLAN.md](PLAN.md)规划，正式入书遵守项目 `AGENTS.md` 和 `book/TEMPLATE.md`。 |

本 Skill 管教学与选材。大批量生成句集、系统语法指南仍可使用项目现有 `english-content-forge`；从英文原文挖句式骨架可使用 `frame-miner`。只有任务确实需要时才读或调用它们。

## 纲领：保留交际作用，允许形式重组

中文提示必须给足**谁说、对谁说、在什么情境、想达到什么效果、希望什么语气**。让学习者先决定“我要做什么表达动作”，再选英文结构。审校译文时依次检查：

1. **事实与关系**：谁做了什么，时间、条件、否定、因果、承诺有没有变。
2. **交际动作**：是在请求、拒绝、解释、试探、安慰、评价，还是结束谈话。
3. **立场与语气**：确定程度、礼貌、亲疏、情绪力度和说话媒介是否合适。
4. **英文成形**：搭配、句式、信息顺序是否自然；不能只因与参考答案不同就判错。

可用“中文原意 → 自然英文 → 英文直译回中文”显示差异。回译用于指出**比喻、重心、显隐、语气**的改变，不要求字面往返一致，也不能仅凭回译不一致宣称“中文思维／英文思维”有某条普遍定律。例如“还不想给关系判死刑”可以说 `I'm not ready to give up on us yet`；回译成“还没准备好放弃我们”时，应检查“我还想尝试”的意图是否保留，以及“别过早下结论”的含义是否被弱化。若后者重要，可讨论 `I don't want to write us off yet`。

一题可有数种合适译法。优先给一个稳妥、常用的说法，再给**确实改变语气或信息重心**的变体；不为凑数罗列同义句。把“有错”“可用但不贴场景”“只是风格不同”分开。避免把自造英文说成语料原句，避免把用户一次拼写失误概括成长期能力缺陷。

## 训练循环

1. **选题**：优先用户真想说的话、真实英文阅读遇到的表达障碍；兼顾计划中的功能和领域缺口。新题先给中文情境与任务，不提前露出英文答案。用户只问一个词或一句，可先解决一个，不机械凑题数。
2. **原答**：保留用户首次作答和不确定点；必要时问“你想强调哪层意思”，不要替用户补造原题或原答。
3. **反馈**：先说明信息是否传达，再区分搭配、结构、语气和用词精度；挑当次最影响表达的少数问题精讲。指出某个改写**增加、删除或改变了什么意思**，不把模型偏好包装成唯一地道说法。
4. **对照**：给自然英文、必要的替代表达、词组与句式骨架；有真实英语例证时标出处，没有就标“教学自造”。做一次直译回中文，明确保留项与改变项。
5. **迁移**：换说话对象、语域或领域，给未见过的新情境，让用户重新表达；以后再做一次不看答案的延迟提取。阅读英文原文、复述和自由表达与中译英交替使用。
6. **记录**：把“已收集素材、已讲解、借提示答对、独立表达、延迟迁移通过”分开记录。网页阅读、看过参考答案或 AI 给出的译文都不是掌握证据；无作答则不生成分数。

反馈的一次最小产物应让用户看见：**我本来要表达什么 → 我写出了什么 → 哪里偏移 → 一种更合适的说法 → 换场景还能不能用**。回答长度随用户问题调整，优先清楚而非铺满所有义项。

## 课程与覆盖

按 [PLAN.md](PLAN.md)从少量真实任务试练，再按证据扩展。难度不能只按词数或句长排序：还要看是否有多重意图、隐含立场、受众差异、语域切换、跨句衔接及可选译法。用户的主干提取已表现较好，但主动表达样本不足；从简短任务校准后尽快加入有选择压力的整句表达，不把基础题长期重复。

覆盖要同时看**交际动作、领域、语域／媒介、语言机制**；覆盖表是课程地图，不是掌握率。一个中文提示不需穷尽全部英文改写；保留代表性说法、适用边界与新语境验证。缺口由真实错误、真实英文语料和使用需求共同决定，不以固定总句数当完成标准。

## 资料与 Book 的边界

采集规则、来源类型、记录字段、去重和质量门槛见 [references/sources-and-coverage.md](references/sources-and-coverage.md)。中文情境和英语原句应分别建候选；即使来自双语材料，也要核对原文、译文和语域，不把平行句对当唯一答案。若需下载资料，遵守项目 `materials/HANDBOOK.md` 的下载和许可记录规则。

只有经审校且值得复用的表达才编入 `book/10-expression/` 或相关专题；需有情境、对照、边界与新语境练习。实际增编按用户请求执行，并同步 `nav.json`、`book/CHANGELOG.md`、`book/BACKLOG.md`；学习掌握只写进进度证据，不由教材篇数推断。涉及私人消息时，公开教材用去身份化的教学情境。

## 方法依据的边界

[Swain & Lapkin 的产出研究](https://academic.oup.com/applij/article-abstract/16/3/371/184113)支持“表达会暴露语言缺口”的机制；[Laufer & Girsai 的词汇／搭配研究](https://academic.oup.com/applij/article-abstract/29/4/694/183330)支持特定教学条件下翻译加对比反馈的记忆收益。这些不证明中译英单独足以带来整体流利，也不支持给所有人规定固定题量或时长。项目现有输入原则见 `background/METHOD.md` 与 `engineering/methodology/2026-09-14-input-principles.md`。
