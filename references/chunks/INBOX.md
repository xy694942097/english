# Chunks 收集箱

录入格式与去重规则见 [收集箱格式](FORMAT.md)。以后在 English 项目中说“帮我录入”，由 Codex 在相应分类的表格中新增一行；网站只负责查看。例句格可附来源；没有例句时写“待补例句”，不阻止先收集。
